# Result — LING-002 / Global Case 015

## 1. Main result

Presupposition provides an external semantic/pragmatic case where background conditions, asserted content, and interpretation outcome are not automatically identical.

A useful abstract form is:

`context support -> interpretable update -> asserted result`.

The source theories do not all implement this chain in the same way, but several major dynamic and Frege-Strawson-style approaches explicitly preserve the distinction.

## 2. Presupposition is not asserted content

In dynamic-semantic treatments, an utterance may be modeled as a context-changing operation with a precondition. The presupposition concerns what must already be supported or made available for the update to proceed normally, while the assertion contributes a distinct update.

Therefore:

`presupposed background != asserted proposition`.

A speaker can presuppose `p` while asserting `q`; treating `p` as if it were simply another asserted conjunct loses the distinction between background requirement and foreground contribution.

## 3. Presupposition failure is not forced to equal falsity

Under a partial update model, if the input context fails the presupposition condition, the update is undefined. A successfully interpreted assertion that evaluates negatively is a different state: its update is defined, even if the resulting context becomes empty.

Thus the case supports the structural distinction:

`failed precondition != defined false/rejecting result`.

This is corroborated by Frege-Strawson-style theories that allow truth-value gaps under presupposition failure.

However, Russellian/bivalent treatments show that ordinary falsity remains a legitimate alternative analysis under a different semantic theory. Hence the external field does not force one unique encoding.

## 4. Accommodation is explicit repair, not retrospective presence

Dynamic semantics and pragmatics allow accommodation: when a presupposition is not already supported, the discourse context may be adjusted so that interpretation can proceed.

Structurally, this is important because accommodation is an extra operation:

`C -> ACC_p(C) -> U_u(ACC_p(C))`.

It is not legitimate to infer from the successful accommodated interpretation that `p` was already present in the original context `C`.

This is the strongest predefinition-restraint result of the case:

**A missing prerequisite may be supplied by an explicit repair/update rule, but the repair must not be confused with evidence that the prerequisite originally existed.**

## 5. DSD correspondence

The Formation Axiom System independently distinguishes staged formation, partial assignment, undefined status, defined zero, and channel absence. In particular, Primitive Axiom V treats values outside the assignment domain as undefined rather than as zero, and Stage VI treats failure of a required condition as channel absence rather than as a zero-valued channel.

This supports an application-level mapping in which:

- context support is a prerequisite layer;
- successful semantic update is a later formed state;
- presupposition failure is not automatically assigned a normal truth value;
- accommodation is an explicit external bridge/repair.

The mapping is structural only. Linguistic presupposition is not a DSD primitive, and DSD does not derive a theory of common ground, projection, accommodation, or assertion.

**Judgment: structural correspondence after explicit encoding.**

## 6. Counterpressure

1. Some semantic theories preserve classical bivalence and analyze presuppositional effects pragmatically.
2. Accommodation means missing background does not always terminate interpretation.
3. Different triggers project presuppositions differently through negation, conditionals, conjunction, and attitude contexts.
4. Common ground is an inter-agent pragmatic structure not supplied by the Formation system.
5. Therefore DSD cannot claim that natural language universally follows one partial-function semantics.

## 7. Relation to LING-001

LING-001 established:

`expression availability != semantic typing != denotation/reference != defined truth output`.

LING-002 adds a different distinction:

`context prerequisite != asserted content != update result`,

and shows that a failed prerequisite can be repaired by an explicit context operation without becoming identical to a pre-existing fact of the original context.

This is an independent linguistic node rather than a duplicate of reference failure.

## 8. Axis-Property System

Not required for the core result. Axis-Property machinery may become useful later when the same expression receives different tag-sensitive semantic/pragmatic properties across speaker roles, discourse contexts, or institutional settings.

## Final judgment

- **No contradiction with the Formation Axiom System was found.**
- **External corroboration was found for separating prerequisite status, assertion, and defined semantic outcome.**
- **Accommodation independently supports the rule that a missing prerequisite may be added only through an explicit repair operation; successful repair does not prove prior presence.**
- **The result supports predefinition restraint but does not establish a uniquely DSD theory of presupposition.**

Overall classification: `structural reinterpretation = supported`, `coherence = supported`, `predefinition restraint = independently corroborated`, `unique DSD semantics = not supported`.
