# Case 006 — Source notes

## DSD source basis

Primary internal source: Kwon Dominicus, *Formation Axiom System — Dimensional-Structural Describability* (2026).

Relevant formal points:

- Primitive Axiom III constrains sound realization but explicitly states that realization alone does not imply configuration describability.
- Definitional Closure Clause IV fixes `Descfg_L(p)` exactly by the primitive witness formula `Psi_L(p)`.
- `Psi_L(p)` requires a restriction-realization witness with a describable restricted expression and all configuration-admission/coherence predicates.
- The full descriptor retains the complete candidate-configuration class, including failed candidates.
- Remark 6.9 states that arbitrary induced subsets need not be formation submodels: deleting every witness of a retained configuration can change `Psi`.

These points mean that no external metatheoretic fact, by itself, is a formal input to `Descfg_L`; only the declared regime data are.

## External source basis

### Baltag, Moss, Solecki

A. Baltag, L. S. Moss, S. Solecki, *The Logic of Public Announcements, Common Knowledge, and Private Suspicions*, TARK VII (1998); CWI technical report version (1999).

CWI record:
https://ir.cwi.nl/pub/4497/

The work treats epistemic actions such as announcements within multi-agent Kripke semantics and develops a dynamic epistemic logic for information-changing events.

### van Benthem, van Eijck, Kooi

J. van Benthem, J. van Eijck, B. Kooi, *Logics of Communication and Change*, ILLC PP-2005-09; later Information and Computation 204(11) (2006), DOI 10.1016/j.ic.2006.04.006.

ILLC preprint record:
https://eprints.illc.uva.nl/id/eprint/154/

The work explicitly treats informational events as model-shifting operations and distinguishes information change from factual alteration.

### ILLC Dynamic Epistemic Logic research line

ILLC overview of announcements:
https://archive.illc.uva.nl/lgc/del/r01-announ.html

It describes a public announcement as reducing the range of epistemic alternatives in a way transparent to the agents.

## Source-discipline warning

PAL `knowledge`, `world`, `accessibility`, and `announcement` are not identified with DSD `describability`, `candidate configuration`, `restriction`, or `realization`.

The comparison concerns only the discipline of keeping external truth, agent information state, and model update distinct. Any direct epistemic interpretation of a DSD regime requires additional encoding that the Formation core does not itself supply.
