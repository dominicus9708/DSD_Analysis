## 1. Source target

Primary target: Hilary Putnam, **"The Meaning of 'Meaning'" (1975)**.

The original Twin Earth case is treated first as an argument about linguistic reference/meaning for natural-kind terms. Later extensions to broad mental content are not silently attributed to Putnam's original argument; they require a separate bridge and separate source audit.

## 2. Neutral setup to preserve

The preparation fixes only the source-level setup needed for later analysis.

- Earth contains ordinary water, later chemically identified as `H2O`.
- Twin Earth contains a macroscopically similar liquid, `XYZ`, in the corresponding oceans, lakes, rain, taps, and ordinary uses.
- The classic comparison is set before mature chemistry, around 1750.
- Earth Oscar and Twin Oscar are intended to be internally/psychologically alike in the relevant pre-chemical regime.
- Their corresponding utterance form `water` is the same at the phonetic/syntactic level.
- Putnam's intended semantic conclusion is that the Earth and Twin-Earth terms differ in extension/reference because the environmental natural kinds differ.

The analysis must not replace this source formulation with the later slogan that all mental content is externally individuated.

## 3. DSD application-level objects

No DSD primitive is identified with meaning, reference, natural kind, belief, or mental content.

Use application-level notation only.

Let:

- `O_I(x)` = internally admitted description of subject `x` under the chosen pre-chemical regime;
- `E(x)` = relevant external environmental structure accessible to the analyst/narrator;
- `u_x` = the subject's token/use of the surface form `water`;
- `R(u_x)` = application-level referent/extension assignment for that token;
- `S_R` = the semantic/reference signature that states which environmental, historical, communal, or usage relations are constitutive of `R`;
- `A_x` = the information actually available to subject `x` at the relevant time.

The intended source setup may permit:

`O_I(Oscar_E) = O_I(Oscar_T)`

while

`E(Oscar_E) != E(Oscar_T)`.

The audit does **not** assume in advance whether this entails

`R(u_E) != R(u_T)`.

That implication is one of the objects to analyze.

## 4. Primary DSD audit questions

### Q1 — internal equality versus reference equality

Does equality of the admitted internal descriptor imply equality of linguistic reference?

`O_I(Oscar_E) = O_I(Oscar_T) -> ? R(u_E) = R(u_T)`

DSD should first ask whether `R` is defined as an internal property, an environment-indexed relation, a causal-historical relation, a community-level property, or something else.

### Q2 — narrator-fixed difference versus subject-accessible difference

The narrator is stipulated to know that Earth has `H2O` and Twin Earth has `XYZ`, while the 1750 subjects need not be able to discriminate those microstructures.

Separate:

`E_E != E_T`

from

`A_E` or `A_T` containing a discriminator for that difference.

The later audit must not treat narrator knowledge as if it were an internal subject description.

### Q3 — property signature before value comparison

Before writing `R(u_E) != R(u_T)`, specify the semantic/reference signature `S_R`.

At minimum ask which of the following are constitutive inputs:

- immediate perceptual/functional profile;
- environmental microstructure;
- causal contact;
- historical linguistic chain;
- communal linguistic practice;
- expert division of linguistic labor;
- speaker intention or internal concept.

Different signatures may define different legitimate properties. DSD must not collapse them merely because all are called `meaning` or `reference`.

### Q4 — same surface token versus same semantic record

The same surface form does not automatically identify the same typed semantic record.

Audit whether:

`same phonetic/syntactic form -> same semantic/reference object`

is being assumed, denied, or independently justified.

### Q5 — source argument versus mental-content extension

Putnam's original natural-kind argument is first a linguistic/reference argument.

If a later formulation concludes:

`same intrinsic subject state + different environment -> different belief/mental content`,

then identify the extra bridge from linguistic reference individuation to mental-content individuation rather than treating the extension as part of the original proof.

### Q6 — externalism as a definition/constitutive rule versus an empirical inference

If a theory explicitly defines natural-kind reference partly through causal/environmental relations, then different environments may yield different reference by the semantic rule itself.

That is structurally different from inferring a hidden environment solely from an internal output.

The audit must distinguish:

- **constitutive externalism**: environment is part of the semantic signature;
- **inverse reconstruction**: one attempts to infer the external environment from internal or surface data alone.

### Q7 — counterpart/comparison domain

Clarify which items are being compared across Earth and Twin Earth:

- subject bodies;
- internal states;
- token forms;
- usage roles;
- environmental substances;
- communal linguistic histories;
- referent assignments.

Equality at one comparison level must not be silently promoted to equality at every level.

## 5. Likely DSD resources

The later analysis should draw only where a real mapping exists from:

1. **Formation Axiom System** — typed formation, observer/regime distinctions, domain-specific interpretation maps, and non-equivalence of reduced description and full structure.
2. **Axis-Property Axiom System** — property name alone has no content; signature/domain/assignment/status must be fixed before comparison.
3. **Channel-Indexed Static Aggregation** — equal reduced/surface records do not reconstruct hidden support or full structure without an injectivity/reconstruction condition.
4. **Structural Reorganization Dynamics** — use only if the analysis opens causal-historical or diachronic reference chains; do not introduce dynamics merely because it is available.

## 6. Failure conditions

PHIL-004 must record a DSD attack as failed if any of the following occurs:

- Putnam already explicitly supplies the exact bridge DSD claims is missing;
- DSD mistakes a constitutive semantic rule for an illicit inverse inference;
- DSD attacks internal indistinguishability even though the thought experiment intentionally grants it and the conclusion concerns an externally individuated relation;
- DSD collapses Putnam's linguistic-reference conclusion with later mental-content externalism;
- a proposed countermodel merely changes Putnam's stipulated semantic theory instead of showing underdetermination within that theory.
