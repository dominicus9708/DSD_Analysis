# DSD Analysis Four-Mode Validation Protocol

Status: **methodological protocol adopted for future validation campaigns**.

This protocol separates four evidential modes so that DSD Analysis is not evaluated only by cases in which it appears to succeed.

## 1. Mode A — Negative-Control / Failure Recording

Purpose: test whether DSD Analysis can reject its own initially plausible attack or mapping.

A case belongs here when a DSD-derived criticism, distinction, or proposed contradiction fails after source reconstruction, formal audit, counterexample search, or external verification.

Required recording:

- the original DSD prediction or attack;
- the falsification criterion fixed before resolution;
- the source or construction that defeats it;
- whether the failure is total, scope-limited, or a level mismatch;
- what rule is changed or retired after failure.

A failure must not be rewritten as a success merely because the audit process was useful.

Canonical current example:

- PHIL-001 first attack: the blanket premise-loading charge against Chalmers's mature zombie argument failed.

Interpretive value:

`DSD application != automatic DSD-favorable verdict`.

## 2. Mode B — Historical Convergence / Independent Rediscovery

Purpose: test whether DSD Analysis independently reaches a distinction, objection, or structural node already established in an external literature.

Procedure:

1. derive the DSD analysis from the source case and current DSD rules;
2. seal the result when feasible;
3. search the external literature for precedent and neighboring formulations;
4. classify the relation as exact match, close convergence, broader family, or only superficial similarity.

Required recording:

- what was independently derived;
- when the derivation was sealed relative to the dedicated literature search;
- the closest prior art;
- the overlap and non-overlap;
- whether the result is counted as an independent evidence node.

Do not claim novelty when the result belongs to an established external family.

Canonical current example:

- PHIL-001 descriptor-completeness squeeze converged with Stoljar/Russellian families.

Interpretive value:

`independent structural convergence -> external calibration`, not proof of DSD axioms.

## 3. Mode C — Prospective / Blind Prediction

Purpose: test out-of-sample problem-finding ability and reduce hindsight fitting.

The prediction stage must be isolated from dedicated objection/reply literature as far as realistically possible.

### Prediction seal

Before opening the comparison literature, create a timestamped `PREDICTION.md` or equivalent containing:

- source formulation used as input;
- information deliberately withheld;
- DSD-predicted vulnerabilities;
- DSD-predicted surviving parts;
- inapplicable DSD attacks;
- required bridge conditions;
- explicit failure criteria.

After the seal, do not silently edit the prediction. Corrections must be appended as post-seal amendments with reasons.

### Post-unblinding comparison

Classify outcomes at minimum as:

- `C1` — DSD prediction matches established literature;
- `C2` — DSD produces a finer or differently formalized distinction within an established family;
- `C3` — important external objection was missed by DSD;
- `C4` — DSD predicts a surviving issue not located in the dedicated search.

`C4` is a research lead, not automatic proof of novelty. A broader novelty search is required before any priority claim.

Interpretive value:

`prospective success -> evidence of out-of-sample analytical capacity`.

## 4. Mode D — Synthetic / Controlled Cases

Purpose: test internal discrimination with known ground truth rather than relying only on historically famous cases.

Construct cases in which the hidden target mechanism is fixed independently of the DSD analysis. Candidate mechanisms include:

- premise loading present / absent;
- observer-information leakage present / absent;
- part-to-whole attribution error present / absent;
- descriptor incompleteness present / absent;
- undefined/absent/zero conflation present / absent;
- valid bridge explicitly supplied / bridge absent;
- structurally clean control with no intended defect.

The analyst must not know which mechanism was planted until after the prediction is sealed.

Required outputs:

- hidden ground-truth specification;
- blinded case statement;
- sealed DSD judgment;
- unblinding result;
- false-positive, false-negative, and correct-detection classification;
- failure analysis when DSD misclassifies the case.

Where multiple synthetic cases are used, report counts rather than only successful examples.

Interpretive value:

`controlled discrimination -> internal validity of the audit rules`.

## 5. Evidence accounting

These four modes answer different questions and must not be merged into one undifferentiated success count.

| Mode | Main question | Success means | Failure means |
|---|---|---|---|
| A. Negative control | Can DSD reject itself? | false attack is discarded | confirmation-bias risk if it cannot |
| B. Historical convergence | Can DSD independently recover known structure? | calibrated convergence | missed/forced mapping |
| C. Prospective blind | Can DSD find structure before seeing replies? | out-of-sample prediction | miss or hindsight dependence |
| D. Synthetic control | Can DSD discriminate known mechanisms? | internal detection accuracy | false positive/negative |

No single mode proves the Formation Axiom System or Axis-Property Axiom System true as metaphysics or physics.

The legitimate cumulative claim is narrower:

`DSD distinctions repeatedly function as useful analytical operators under controlled and externally calibrated tests`.

## 6. Publication rule

A validation paper should preserve all four result directions when available:

- DSD failure;
- external convergence;
- prospective prediction;
- synthetic controlled performance.

Do not remove negative results because they weaken a narrative. A failure case can increase the credibility of a later positive case by showing that the method does not mechanically return DSD-favorable judgments.

## 7. Novelty rule

The novelty ladder is:

1. **rephrasing** — same objection in DSD vocabulary;
2. **formal sharpening** — established issue given a more explicit structural form;
3. **independent rediscovery** — result derived before dedicated precedent search;
4. **prospective prediction** — result sealed before reply literature is opened;
5. **novel objection/result** — no materially equivalent precedent found after broad novelty search and the result survives source-level rebuttal.

Only level 5 should be described as a new philosophical objection without qualification.
