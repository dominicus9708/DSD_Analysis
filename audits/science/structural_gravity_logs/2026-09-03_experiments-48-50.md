## Experiment 48 — Scale-free source-removal propagation audit

### Generalized source-change distance

Let a structural source change occur at time \(t_0\) on a physical support

\[
\operatorname{supp}\Delta S.
\]

For a field point \(x\), define the causal source distance

\[
d_S(x)=\operatorname{dist}\!\left(x,\operatorname{supp}\Delta S\right).
\]

The previously used \(r/c_{\rm info}\) delay is only a special case, such as a pointlike change at the origin. For an extended source whose changed region reaches radius \(R\), an exterior point at radius \(r>R\) has the shortest geometric distance \(r-R\), provided the change is physically specified over that source region at \(t_0\).

### Common-scale-invariant temporal discrepancy

Let \(a^-(x)\) be the pre-change response and \(a(x,t)\) the later response. Define

\[
D_t(x,t)
=
d_{\rm sf}\!\left(a(x,t),a^-(x)\right),
\]

using the common-scale-invariant discrepancy from Experiment 45.

For a diagnostic threshold \(\epsilon>0\), define

\[
\tau_\epsilon(x)
=
\inf\{t\ge t_0:D_t(x,t)\ge\epsilon\}.
\]

If the dynamics has finite propagation bound \(c_{\rm info}\) and the response is unchanged outside the causal cone, then every finite threshold crossing obeys

\[
\boxed{
\tau_\epsilon(x)-t_0
\ge
\frac{d_S(x)}{c_{\rm info}}.
}
\]

The unknown multiplicative response normalization cancels from \(D_t\).

### Radial onset-speed estimator

For a coherent radial front and two radii with finite onset times,

\[
v_\epsilon(r_1,r_2)
=
\frac{d_S(r_2)-d_S(r_1)}{\tau_\epsilon(r_2)-\tau_\epsilon(r_1)}.
\]

A consistent finite-propagation front must satisfy

\[
\boxed{v_\epsilon\le c_{\rm info}}
\]

under the stated localization and front-identification assumptions.

### Three times must remain distinct

- earliest causal time:
  \[
  t_{\rm causal}=t_0+d_S/c_{\rm info};
  \]
- threshold response onset \(\tau_\epsilon\);
- later relaxation or equilibration time.

Finite \(c_{\rm info}\) constrains the first and therefore the earliest possible onset, but does not determine the relaxation time or response amplitude.

### Verdict

- universal use of \(r/c_{\rm info}\) for extended-source changes: **REJECTED**.
- general source-change distance \(d_S/c_{\rm info}\): **CONFIRMED as the correct geometric causal form**.
- amplitude-free onset test: **CONFIRMED**.
- finite propagation determines relaxation time: **REJECTED**.

## Experiment 49 — Four scale-free structural-gravity tests

The unknown absolute normalization is separated from four testable structural claims.

### 1. Internal-structure universality

\[
U_{\rm str}(r;M)=D_{a\mid M}(r;M).
\]

Target:

\[
U_{\rm str}\to0.
\]

### 2. Distance exponent

\[
p_{\rm eff}(r_1,r_2;S)
= -\frac{\ln|a_S(r_2)/a_S(r_1)|}{\ln(r_2/r_1)}.
\]

Inverse-square target:

\[
p_{\rm eff}\to2.
\]

### 3. Source-mass exponent

\[
q_{\rm eff}(M_1,M_2;r)
=
\frac{\ln|a_{M_2}(r)/a_{M_1}(r)|}{\ln(M_2/M_1)}.
\]

Linear-mass target:

\[
q_{\rm eff}\to1.
\]

### 4. Propagation onset

\[
\tau_\epsilon(x)-t_0
\ge
\frac{d_S(x)}{c_{\rm info}},
\]

or equivalently, for a coherent front,

\[
v_\epsilon\le c_{\rm info}.
\]

### Independence

These four statements are logically independent. Passing any subset does not establish the others.

The remaining fifth problem is the absolute normalization \(K_*\), which none of these scale-free tests determines.

Hence the structural-gravity audit is organized as

\[
\boxed{
U_{\rm str}
\oplus
p_{\rm eff}
\oplus
q_{\rm eff}
\oplus
v_{\rm onset}
\oplus
K_*.
}
\]

### Verdict

- absolute-coupling failure blocks all structural predictions: **REJECTED**.
- four structural claims can be audited independently of \(K_*\): **CONFIRMED**.

## Experiment 50 — Linear kernel flattening implies scale-free structural homogenization

### Setup

In the spherical linear control specialization, let

\[
a_\rho(r)
=
K_*\int_0^R
\left[g_0(r)+\varepsilon(r,s)\right]\rho(s)\,d\mu(s),
\]

with

\[
\int_0^R\rho(s)\,d\mu(s)=M.
\]

Then

\[
a_\rho(r)=K_*\left[g_0(r)M+e_\rho(r)\right],
\]

where

\[
|e_\rho(r)|\le M\|\varepsilon_r\|_\infty.
\]

Define the relative kernel nonuniformity

\[
\eta(r)
=
\frac{\|\varepsilon_r\|_\infty}{|g_0(r)|},
\qquad \eta(r)<1.
\]

### Pairwise response bound

For any two nonnegative same-mass profiles \(\rho_1,\rho_2\),

\[
|a_{\rho_1}-a_{\rho_2}|
\le
2|K_*|M\|\varepsilon_r\|_\infty.
\]

Also

\[
|a_{\rho_i}|
\ge
|K_*|M|g_0(r)|(1-\eta(r)).
\]

Therefore the scale-free discrepancy obeys

\[
\boxed{
d_{\rm sf}(a_{\rho_1},a_{\rho_2})
\le
\min\!\left\{1,\frac{\eta(r)}{1-\eta(r)}\right\}.
}
\]

Taking the supremum over the same-mass density fiber gives

\[
\boxed{
U_{\rm str}(r;M)
\le
\min\!\left\{1,\frac{\eta(r)}{1-\eta(r)}\right\}.
}
\]

Hence

\[
\boxed{\eta(r)\to0\Rightarrow U_{\rm str}(r;M)\to0.}
\]

The unknown absolute factor \(K_*\) cancels completely.

### Interpretation

The earlier statement that the far-field response kernel loses source-internal resolution now has a direct quantitative consequence: relative flattening of the internal-coordinate kernel is sufficient for same-mass source-response homogenization.

### Not a necessary condition

Pointwise kernel flattening is stronger than required. If the admissible source family explores only a restricted set of density perturbations, kernel variations orthogonal to every admissible zero-total perturbation may remain without producing response differences.

Thus

\[
\boxed{
\text{kernel flattening is sufficient, not necessary, for }U_{\rm str}\to0.
}
\]

### Verdict

- relative kernel flattening \(\eta\to0\) implies same-mass response homogenization: **CONFIRMED in the linear control specialization**.
- kernel flattening is necessary for homogenization: **REJECTED**.
- the result determines the absolute response normalization: **REJECTED**.

## Consequence for the research line

Experiments 31 and 45 are now linked quantitatively:

\[
\text{loss of internal-coordinate kernel resolution}
\Rightarrow
\text{small same-mass fiber diameter}.
\]

The next target is to replace the linear-kernel sufficient condition by a nonlinear stability condition on the response map over each total-mass fiber, so that the same homogenization criterion applies without assuming linearity.
