# Result — LING-001 / Global Case 014

## 1. Main finding

Formal semantics independently preserves several distinctions that are structurally similar to DSD Formation staging, but there is no canonical one-to-one identification between linguistic statuses and Formation predicates.

A useful external sequence is:

`raw form -> syntactically generated expression -> type-compatible semantic composition -> denotation/reference status -> truth-conditional output`

The exact number and organization of stages are theory-dependent.

## 2. Expression occurrence is not successful semantic interpretation

A surface string or token can exist without belonging to the grammar-generated expression set of a formal fragment.

Let `Sigma*` be the set of raw strings and `Exp_L` the expressions generated by the grammar of language fragment `L`.

Then in general:

`u in Sigma*` does not imply `u in Exp_L`.

This is only a preliminary analogue of DSD candidate/admission separation. DSD does not contain a grammar, and grammatical well-formedness is not literally Formation admission.

**Judgment: weak structural correspondence.**

## 3. Syntactic combination and semantic type compatibility are distinct theoretical coordinates

Montague-style semantics systematically relates syntactic categories and semantic types. Under functional-application accounts, an application is well-typed only when the argument denotes an input of the type for which the function is defined.

For example, with base types `e` and `t`:

- `mira : e`
- `sleeps : e -> t`

`sleeps(mira)` is well-typed and returns a truth-valued expression, whereas the reversed application `mira(sleeps)` is not licensed by the selected typed functional rule.

The important DSD-relevant point is not that linguistic type checking *is* Formation restriction or admission. It is that a downstream operation can require an explicit domain condition, and failure of that condition is not itself an ordinary semantic output value.

**Judgment: structural correspondence after encoding.**

## 4. Non-denotation is not defined falsity

Free logic was developed precisely because a singular term can fail to denote without the language simply ceasing to contain that term. Different free-logical semantics then treat formulas containing empty terms in different ways.

Therefore the following must not be collapsed without an explicit semantic rule:

`term syntactically available`

`term denotes`

`sentence containing the term has a defined truth value`

`sentence is false`.

In the finite witness, `n0` is syntactically typed as an individual term but left non-denoting in the chosen partial-reference interpretation. This status differs from a denoting individual for which the predicate application is defined and evaluates to `FALSE`.

Thus:

`reference undefined != truth value FALSE`.

This is the strongest external analogue to the Formation system's insistence that undefined status, defined zero-like output, and absence are not automatically identical.

However, free logic also provides a major boundary: there is no single universally required truth-value treatment for empty terms. Negative, positive, neutral, supervaluational, and other treatments can differ. DSD therefore cannot claim that linguistics independently forces one specific partial-value semantics.

**Judgment: strong status-separation corroboration; no unique semantic encoding.**

## 5. Compositionality adds a different but compatible lesson

The principle of compositionality says, in its standard family of formulations, that the meaning of a complex expression is determined by the meanings of its constituents and their mode of combination.

This supports the general idea that a complex semantic result is not licensed merely by the presence of component expressions; the relevant constituent meanings and combination structure must be supplied.

But compositionality is not DSD Formation Closure VII. It concerns linguistic meaning determination, not formation channels or finite component-term aggregation.

**Judgment: methodological analogy only.**

## 6. Predefinition-restraint result

The case independently supports a restrained rule:

**A missing denotation, failed type application, or unavailable interpretation must not be replaced by an ordinary semantic value unless the semantic theory explicitly introduces that completion rule.**

Formally, if an interpretation is partial,

`I : Exp_L partial-> D`,

then

`e notin dom(I)`

cannot be inferred to mean

`I(e) = d0`

for some ordinary `d0 in D` without an additional totalization convention.

A totalized representation can still be faithful if it carries a disjoint sentinel/status tag from which the original partial state can be reconstructed. This matches the earlier DSD analysis of status-preserving encodings.

## 7. Counterpressure

The strongest counterpressure is that many formal semantic systems are deliberately designed so that every grammar-generated expression receives an interpretation of the required type, while ill-typed strings are excluded earlier by syntax or semantic composition rules.

Therefore a semantic theory may compress several of the above stages into its signature and formation rules.

This does not contradict DSD. It shows that DSD's staged distinctions are a modeling discipline, not a claim that every linguistic theory must expose every stage as a separate primitive object.

A second counterpressure is that reference failure can be handled without partial truth-value assignment. Free-logical variants demonstrate that a non-denoting term does not force one particular status representation.

## 8. Formation Axiom System correspondence

The Formation source explicitly provides:

- typed candidate expression and configuration carriers;
- separate admission/describability coordinates;
- typed restriction and realization conditions;
- quantity-specific partial assignments;
- distinction between undefined assignment and defined values;
- domain-specific applications through additional interpretation maps.

These features make the linguistic application structurally coherent.

But Formation supplies none of the following:

- a grammar of natural language;
- lexical semantics;
- semantic type assignment for linguistic categories;
- a theory of reference;
- truth conditions;
- presupposition, implicature, context update, or pragmatics.

All such content remains external application data.

**Judgment: coherent structural reuse; no linguistic derivation from DSD.**

## 9. Axis-Property System

Axis-Property machinery is unnecessary for the core result. The relevant distinctions already arise before any realized-axis property layer is needed.

It may become useful later for context-sensitive, relational, or role-tagged semantic properties, but LING-001 does not require it.

## 10. Final judgment

- **No contradiction with the Formation Axiom System was found.**
- **Formal semantics independently corroborates the need to distinguish expression availability, typed applicability, denotation/reference status, and defined semantic outputs.**
- **The strongest DSD-relevant result is that reference failure or failed semantic application cannot be silently identified with a defined false/zero-like value without an explicit semantic convention.**
- **The correspondence is not one-to-one and is theory-dependent.**
- **Existing formal semantics already possesses its own machinery for these distinctions; DSD's contribution here is cross-domain structural decomposition, not a replacement semantic theory.**

Overall classification: `structural reinterpretation = supported`, `coherence = supported`, `predefinition restraint = independently corroborated`, `unique linguistic theorem from DSD = not supported`.
