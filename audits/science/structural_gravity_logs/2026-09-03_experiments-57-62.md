## Experiment 57 — Distortion, slope, and acceleration are distinct layers

Let a scalar structural-distortion field be

\[
X:\Omega\to\mathbb R
\]

on a supplied spatial carrier with metric \(g\).
The differential \(dX\) is defined from the scalar field, while the gradient requires the metric:

\[
\nabla_g X=g^{-1}(dX).
\]

Define the geometric distortion-slope vector

\[
s_X:=-\nabla_gX.
\]

This is not yet physical acceleration. Physical acceleration additionally requires a kinematic/time structure and a response bridge

\[
B_{\rm acc}:s_X\mapsto \mathbf a.
\]

Hence

\[
\boxed{X\neq -\nabla X\neq \mathbf a}
\]

as logical layers.

## Experiment 57-B — Normalization degeneracy

If

\[
X'=\alpha X+\beta,
\]

then

\[
\nabla X'=\alpha\nabla X.
\]

For a linear local response

\[
\mathbf a=-\kappa\nabla X,
\]

the same acceleration is obtained from \(X'\) with

\[
\kappa'=\kappa/\alpha.
\]

The additive offset \(\beta\) disappears from the gradient, while multiplicative normalization of \(X\) is degenerate with the response coefficient. Therefore writing \(\mathbf a=-\nabla X\) directly fixes a normalization convention unless \(X\)'s absolute physical scale is independently determined.

## Experiment 58 — Isotropic local first-order response theorem candidate

At a point, suppose the only directional input to a local response is \(\nabla X\), together with scalar data and an isotropic metric. An orthogonally equivariant local vector response must be parallel to \(\nabla X\). Hence the general first-order isotropic form is

\[
\boxed{
\mathbf a
=-\kappa\!\left(X,\|\nabla X\|^2,\ldots\right)\nabla X
}
\]

up to the separately selected sign/orientation convention.

Thus isotropy can constrain the response direction without fixing its magnitude. If additional directional structural inputs exist, such as preferred axes or anisotropic property data, this reduction need not hold.

## Experiment 59 — Center-depth/slope separation

For a differentiable spherically symmetric distortion field \(X(r)\), symmetry gives

\[
\nabla X(0)=0.
\]

Therefore under the isotropic local bridge,

\[
\mathbf a(0)=0
\]

even when the center is a maximum-distortion point. Meanwhile

\[
\nabla^2X(0)
\]

need not vanish. Hence distortion depth, slope, and second-order curvature remain distinct diagnostics:

\[
\boxed{
X\text{ depth}\neq \nabla X\text{ slope}\neq \nabla^2X\text{ curvature}
}
\]

This formalizes the earlier thought-experiment intuition that the acceleration graph corresponds more closely to the steepness of a distortion surface than to the distortion amplitude itself.

## Experiment 60 — Response potential is not automatically structural distortion

If an actual conservative acceleration field admits a potential \(\Phi_a\),

\[
\mathbf a=-\nabla\Phi_a,
\]

this does not imply \(\Phi_a=X\).
If instead

\[
\Phi_a=F(X),
\]

then

\[
\boxed{
\mathbf a=-F'(X)\nabla X
}
\]

and the response coefficient is \(\kappa(X)=F'(X)\).
The special equality \(\mathbf a=-\nabla X\) corresponds to the calibration \(F(X)=X+\mathrm{const}\).

## Experiment 61 — Conservative-response condition

For

\[
\mathbf a=-\kappa(\mathbf x)\nabla X,
\]

in a Euclidean three-dimensional specialization,

\[
\nabla\times\mathbf a
=-\nabla\kappa\times\nabla X.
\]

Equivalently in differential-form language,

\[
d(\mathbf a^\flat)=-d\kappa\wedge dX.
\]

A sufficient condition for local conservative response is

\[
\kappa=\kappa(X),
\]

in which case there exists \(F\) with \(F'(X)=\kappa(X)\) and \(\Phi_a=F(X)\).
If \(\kappa\) depends independently on density, relation, or property sectors, nonzero rotational response is logically possible unless additional alignment conditions hold.

## Experiment 62 — Far-field exponent relation

Suppose asymptotically

\[
X(r)\sim A(M)r^{-m},
\qquad
\kappa(r)\sim r^s.
\]

Then the isotropic gradient response gives

\[
|\mathbf a(r)|\sim r^{-(m+1-s)}.
\]

Thus the acceleration distance exponent is

\[
\boxed{p=m+1-s}.
\]

If the response coefficient approaches a nonzero constant, \(s=0\), then \(p=m+1\). In particular, an inverse-square acceleration profile corresponds to an inverse-distance distortion profile only when the asymptotic response coefficient is scale-neutral.

## Verdict

- \(-\nabla X\) as geometric distortion slope: **CONFIRMED once a metric is supplied**.
- \(-\nabla X\) as physical acceleration by definition: **REJECTED unless \(X\) is explicitly defined as a calibrated response potential**.
- isotropy/locality forcing response direction parallel to \(\nabla X\): **CONDITIONALLY_CONFIRMED**.
- response magnitude from geometry alone: **UNRESOLVED**.
- maximum distortion implying maximum acceleration: **REJECTED**.
- conservative response potential identical to structural distortion: **NOT_AUTOMATIC**.
- multiplicative normalization of \(X\) versus response coefficient: **DEGENERATE_UNLESS_INDEPENDENTLY_FIXED**.
