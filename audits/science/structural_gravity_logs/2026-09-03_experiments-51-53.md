## Experiment 51 — Nonlinear detail-sensitivity theorem

### Setup

Let the physical exterior response at radius \(r\) be represented as

\[
E_a^{(r)}(S)=G_r\!\left(M(S),h_r(S)\right),
\]

where

- \(M(S)\) is the chosen coarse total-mass descriptor;
- \(h_r(S)\) is a physical exterior-detail state, not an observer-resolution artifact;
- \(G_r\) may be nonlinear.

On the same-mass fiber \(\mathcal F_M\), define the detail diameter

\[
\Delta_h(r;M)
=
\sup_{S_1,S_2\in\mathcal F_M}
 d_h\!\left(h_r(S_1),h_r(S_2)\right).
\]

Assume a response-continuity modulus \(\omega_r\) such that

\[
d_{\rm sf}\!\left(
G_r(M,h_1),G_r(M,h_2)
\right)
\le
\omega_r\!\left(d_h(h_1,h_2)\right),
\]

with \(\omega_r(0)=0\).

Then

\[
\boxed{
U_{\rm str}(r;M)
\le
\omega_r\!\left(\Delta_h(r;M)\right).
}
\]

Therefore a sufficient nonlinear condition for same-mass far-field homogenization is

\[
\boxed{
\omega_r\!\left(\Delta_h(r;M)\right)\to0.
}
\]

### Lipschitz specialization

If

\[
d_{\rm sf}(G_r(M,h_1),G_r(M,h_2))
\le
L_r d_h(h_1,h_2),
\]

then

\[
\boxed{U_{\rm str}(r;M)\le L_r\Delta_h(r;M).}
\]

Thus far-field structural universality can arise through any of the following:

1. physical detail diameter \(\Delta_h\to0\);
2. response sensitivity \(L_r\to0\);
3. neither factor vanishes separately, but \(L_r\Delta_h\to0\).

The linear kernel-flattening result of Experiment 50 is a special case.

### Non-converse

\[
U_{\rm str}(r;M)\to0
\]

does **not** imply

\[
\Delta_h(r;M)\to0.
\]

Distinct physical details may remain while the response bridge maps them to the same response class.

Hence

\[
\boxed{
\text{response homogenization}\not\Rightarrow\text{internal/detail homogenization}.
}
\]

### Verdict

- nonlinear detail-size × response-sensitivity condition: **CONFIRMED as a sufficient condition**.
- response homogenization implies physical detail erasure: **REJECTED**.

## Experiment 52 — Asymptotic descent to the mass quotient

### Same-mass equivalence relation

Define

\[
S_1\sim_M S_2
\iff
M(S_1)=M(S_2).
\]

The quotient \(\mathcal S/\!\sim_M\) identifies all sources with the same coarse total mass.

At finite radius, the response map \(E_a^{(r)}\) need not be well-defined on this quotient because two equivalent sources can produce different responses.

### Exact descent

If

\[
D_{a\mid M}(r;M)=0
\]

for every admissible mass, then there exists a well-defined map

\[
F_r:\mathcal M\to\mathcal A_r
\]

such that

\[
E_a^{(r)}=F_r\circ M.
\]

### Approximate descent

If

\[
D_{a\mid M}(r;M)\le\epsilon,
\]

choose any representative \(S_M\in\mathcal F_M\) and define

\[
F_r^{(\epsilon)}(M)=E_a^{(r)}(S_M).
\]

Then every \(S\in\mathcal F_M\) obeys

\[
d_{\rm sf}\!\left(E_a^{(r)}(S),F_r^{(\epsilon)}(M)\right)
\le\epsilon.
\]

Thus small fiber diameter means that the response approximately descends to a function of total mass alone.

If

\[
\overline D_{a\mid M}(R;M)\to0,
\]

this approximate descent becomes asymptotically exact in the far field.

### Interpretation

The statement `only total mass remains in the far field` is therefore recast as

\[
\boxed{
E_a^{(r)}\text{ asymptotically descends to the quotient by same-mass equivalence.}
}
\]

This does not imply that the internal states themselves become equivalent.

### Verdict

- finite-radius mass quotient is automatically sufficient: **REJECTED**.
- vanishing same-mass fiber diameter gives asymptotic mass-quotient response: **CONFIRMED**.

## Experiment 53 — Minimal sufficient descriptor set

### Descriptor partial order

Let \(Q_1\preceq Q_2\) mean that \(Q_2\) is at least as informative as \(Q_1\), equivalently every \(Q_2\)-fiber is contained in a \(Q_1\)-fiber.

Examples include

\[
M
\preceq
(M,I_2)
\preceq
C[\rho]
\]

for the spherical density ladder, while bounded-component and density marginals may be incomparable.

For tolerance \(\epsilon\), define the sufficient-descriptor set

\[
\mathfrak Q_\epsilon(r)
=
\left\{
Q:
D_{a\mid Q}(r;q)\le\epsilon
\text{ for every relevant }q
\right\}.
\]

Because refinement only shrinks fibers, \(\mathfrak Q_\epsilon(r)\) is upward closed under descriptor refinement.

### Minimal sufficient descriptors

Define the minimal elements

\[
\operatorname{MinSuff}_\epsilon(r)
=
\operatorname{Min}\mathfrak Q_\epsilon(r).
\]

There need not be a unique minimal descriptor. Multiple incomparable descriptors can each be sufficient.

### Density interpretation

This directly replaces the vague question

`Does density matter?`

with

\[
\boxed{
\text{What is the coarsest/minimal source descriptor through which the response factors at radius }r?
}
\]

Possible outcomes include:

- \(M\) alone is sufficient;
- \((M,I_2)\) is needed;
- a full radial profile is needed;
- a bounded-component marginal and density marginal form incomparable sufficient descriptions;
- no tested coarse descriptor is sufficient.

### Distance dependence

\[
\operatorname{MinSuff}_\epsilon(r)
\]

may change with radius. A structural-gravity far-field coarse limit corresponds to total mass becoming sufficient at large \(r\).

No monotonic simplification with radius is assumed without proof.

### Verdict

- one universal scalar `density importance` measure: **REJECTED**.
- source-descriptor sufficiency as a partial-order/fiber problem: **CONFIRMED**.
- unique minimal sufficient descriptor is guaranteed: **REJECTED**.

## Consequence for the research line

The structural-gravity source problem is now organized without assuming a specific response law:

\[
\boxed{
\text{descriptor lattice}
\to
\text{fiber response diameters}
\to
\text{minimal sufficient descriptors}
\to
\text{far-field quotient descent}.
}
\]

The next target is to combine this descriptor sufficiency structure with the distance- and mass-exponent tests, so that a single candidate model can be audited in the order:

1. minimum source information needed;
2. structural homogenization;
3. radial exponent;
4. mass exponent;
5. finite propagation;
6. only then absolute normalization.
