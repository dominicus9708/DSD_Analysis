# Source Notes — LING-001 / Global Case 014

## DSD source lock
Primary source: *Dimensional-Structural Describability Formation Axiom System* (Kwon Dominicus, 2026-08-06).

Relevant source structure:
- static typed set-theoretic regime;
- candidate structural expressions and candidate configurations are distinct typed carriers;
- Primitive Axiom I separates expression describability from expression admission;
- Primitive Axiom II supplies sound restriction;
- Primitive Axiom III supplies sound realization;
- Definitional Closure IV derives configuration describability only from an explicit witness history;
- Primitive Axiom V uses quantity-specific partial assignments;
- Closure VI forms a channel only from a defined assignment and role data;
- undefined assignment, defined zero, defined nonzero values, and channel absence are structurally distinct;
- domain-specific applications require additional interpretation maps.

No claim is made that linguistic grammaticality, semantic denotation, or reference is literally one of these DSD predicates. Every mapping below is application-level.

## External formal-semantics sources

### Compositionality
Stanford Encyclopedia of Philosophy, "Compositionality".
https://plato.stanford.edu/entries/compositionality/

Use:
- a language has expressions generated by syntactic structure;
- complex meaning is determined, on compositional approaches, by constituent meanings and their mode of combination;
- syntax/constituency and semantic determination are separate theoretical coordinates.

### Montague semantics
Stanford Encyclopedia of Philosophy, "Montague Semantics".
https://plato.stanford.edu/entries/montague-semantics/

Use:
- model-theoretic interpretation of natural-language expressions;
- systematic syntax-semantics relation;
- semantic types are tied to syntactic categories in the formal fragment.

### Typed functional application
Stanford Encyclopedia of Philosophy, "Intensional Transitive Verbs", section on Montague semantics.
https://plato.stanford.edu/entries/intensional-trans-verbs/

Use:
- semantic composition by functional application;
- application is well-typed only when the argument denotes an input of the type for which the function is defined.

### Non-denoting singular terms
Stanford Encyclopedia of Philosophy, "Free Logic".
https://plato.stanford.edu/entries/logic-free/

Use:
- singular terms may fail to denote;
- free-logical systems alter classical existence assumptions rather than treating every syntactically available singular term as necessarily denoting;
- different free-logical semantics handle formulas with empty terms differently, so reference failure does not have one universally forced truth-value treatment.

### Reference
Stanford Encyclopedia of Philosophy, "Reference".
https://plato.stanford.edu/entries/reference/

Use:
- successful reference is a further semantic relation and can fail under competing theories;
- the source discipline itself does not identify mere expression occurrence with successful reference.
