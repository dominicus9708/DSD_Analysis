## Thought-experiment audit matrix

For each source argument, record separately:

| Coordinate | Question |
|---|---|
| setup | What is explicitly stipulated? |
| disputed premise | Which premise would an opponent reject? |
| narrator access | What does the author/reader know from outside? |
| internal access | What can the subject inside the case actually know/observe? |
| derived result | What follows without using the canonical conclusion? |
| alternative models | Can a rival external structure generate the same internal description? |
| bridge principle | Is a part-to-whole, possibility-to-actuality, experience-to-fact, or description-to-existence bridge required? |
| conclusion strength | Demonstration, conditional result, intuition pump, boundary case, or underdetermined? |

## Falsification-first rules

A DSD-friendly reading fails if any of the following is shown:

- the traditional argument already supplies independent evidence excluding all rival structures;
- observer-information separation is irrelevant to the original inference;
- the suspected premise is openly stipulated only for a conditional result and is not later reused as evidence for itself;
- the part/whole or description/existence transfer is supported by an explicit independent bridge principle;
- DSD adds no discriminatory question beyond ordinary reconstruction of the original argument.

A case should be marked as a useful DSD convergence only after these alternatives are tested.

## Evidence accounting

Do not count several thought experiments as independent nodes merely because they have different stories.

Group cases by the mechanism actually tested, such as:

- premise/conclusion loading;
- observer-access asymmetry;
- inverse non-identifiability;
- part/whole attribution;
- modal possibility versus descriptive stipulation;
- experience/fact/ability/representation separation.
