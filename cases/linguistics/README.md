## First-pass result

The campaign is closed at `LING-010` for its original roadmap. Its main use is to preserve distinctions that the source linguistic theories themselves require, including:

- expression availability versus semantic applicability;
- unavailable/undefined versus genuinely defined false or zero-like outputs;
- unresolved multiple interpretations versus one selected interpretation;
- explicit utterance content versus pragmatic inference;
- prerequisite support versus later accommodation or repair;
- discourse state versus ordered update history;
- meaningful locution versus successful speech act and downstream effect;
- directional relation structure versus unary participant labels;
- complete information structure versus reduced/coarse representation.

The campaign does not claim a new DSD grammar, lexical semantics, truth theory, pragmatic theory, or unique linguistic semantics.

## DSD layer use

- **Formation Axiom System:** principal staging/typing layer across the campaign.
- **Axis Property Axiom System:** used selectively where ordered relation-sensitive properties are genuinely part of the source phenomenon.
- **Channel-Indexed Static Aggregation:** used as an information-loss/reduction audit where coarse outputs fail to retain source structure.
- **Structural Reorganization Dynamics:** not identified with linguistic dynamic semantics merely because both use the word `dynamic`.
