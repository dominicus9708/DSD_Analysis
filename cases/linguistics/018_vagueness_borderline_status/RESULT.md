# LING-005 / Global Case 018 — Result

## Question
Can a vague-predicate borderline case be identified with one DSD status such as undefined, zero/false, or an intermediate numerical value without additional theory?

## Result
No.

External theories of vagueness assign materially different structures to apparently similar borderline phenomena:

1. **Supervaluationism** can represent a simple borderline predication through disagreement among admissible precisifications and a truth-value gap at the unprecisified level.
2. **Epistemicism** keeps a determinate bivalent truth value and a sharp boundary, while locating the difficulty in our inability to know the boundary.
3. **Fuzzy / many-valued approaches** can assign a defined intermediate truth degree.

Therefore the surface observation `classification is borderline/difficult` underdetermines the semantic status.

## DSD correspondence
Formation already protects several distinctions relevant to faithful encoding:

- outside assignment domain is not a value;
- defined zero is not undefined;
- defined nonzero/other values remain inside the value carrier;
- absent channels are not zero terms.

This supports a **bridge discipline**: the application must declare which semantic theory and which carrier/status mapping is intended.

However, Formation does **not** itself decide the nature of vagueness. In particular:

- `borderline -> undefined` is not a DSD theorem;
- `borderline -> false/0` is not a DSD theorem;
- `borderline -> 0.5` is not a DSD theorem;
- `borderline -> hidden Boolean truth` is not a DSD theorem.

## Strongest predefinition result
The justified general claim is not `borderline != false` but:

> A borderline presentation does not justify preassigning a semantic completion or truth-status without an explicit external theory/bridge.

This is stronger and more theory-neutral than choosing one favored treatment.

## Pressure on DSD application
A single coarse metadata label such as `uncertain` would be non-faithful if it merged:

- semantic indeterminacy,
- epistemic ignorance of a determinate value,
- defined graded membership/truth.

Thus a DSD analysis should preserve **source-theory status** separately from **observer/analyst accessibility** whenever the external domain distinguishes them.

## Relation to Case 017
- Case 017 ambiguity: several distinct interpretation candidates are available and selection is unresolved.
- Case 018 vagueness: a selected predicate interpretation has borderline application, and competing theories disagree about the status of that borderline.

They are independent structural nodes.
