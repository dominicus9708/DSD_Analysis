# LAW-007 Reproducibility

## Source-first protocol

1. Read the source rule in its own terminology before writing DSD correspondence.
2. Record whether the source distinguishes status/capacity/right, present exercisability, actor authority/support, exercise event, enforcement and effect.
3. Do not import one witness family's vocabulary into another.
4. Build finite witnesses from source-distinct states.
5. Apply Formation only after the source-side record is fixed.
6. Run direct contradiction audit after matching subject, actor, role, right/power, condition, time, regime and effect.

## Sources

- CRPD Article 12, official OHCHR text.
- CRPD General Comment No. 1, official UN/OHCHR materials.
- UNIDROIT Principles, Articles 7.3.2 and Chapter 10 including Article 10.9.
- Vienna Convention on the Law of Treaties, Articles 6-8, official UN Treaty Collection.
- DSD Formation Axiom System current project source.

## Reproduction checks

The analysis should reproduce the following negative tests:

- legal capacity recognized + support required must not become `no capacity`;
- right exists + not yet exercisable must remain distinct;
- exercisable + not exercised must remain distinct;
- limitation defence can bar enforcement without extinguishing the right under the selected UNIDROIT regime;
- State treaty capacity must not be copied into every person's authority;
- unauthorized act must remain represented as an event even when legally ineffective;
- later confirmation must not be prefilled into the earlier descriptor.

## Code

No Python or numerical code is required. LAW-007 is a source-structural and finite-state analysis.
