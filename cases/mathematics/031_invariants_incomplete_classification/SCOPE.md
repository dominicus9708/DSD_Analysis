# Scope

## Included

- Strict axis-property isomorphism as the classification relation.
- Realized-axis rank and matrix-size information.
- Definition 12.3 displayed finite-coordinate scalar summary.
- Proposition 12.4 collision obstruction and Corollary 12.5.
- Standard invariant / complete-invariant distinction.
- Matrix-similarity examples using characteristic data and Jordan structure.
- Downstream static-aggregation and dynamic-readout statements only as corroborating interfaces.

## Excluded

- Claims that every possible DSD descriptor can or cannot be encoded into one scalar.
- Cardinality classification of the whole metatheoretic descriptor class.
- Computational complexity of canonicalization.
- Dynamical evolution except for a short comparison with reduced-readout collisions.
- Physical interpretation of axis properties.

## Boundary rule

A map is not called an `invariant` merely because it is a scalar, descriptor, feature, indicator, or readout. It must first be constant on the equivalence classes under study. Completeness is a second condition: equal invariant values must also force equivalence.
