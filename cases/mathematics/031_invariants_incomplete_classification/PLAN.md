# MATH-004 Analysis Plan

Global case: 031
Domain case: MATH-004

## Question

How do standard mathematical invariants, complete invariants, canonical forms, and incomplete classifiers compare with the DSD axis-property notions of realized-axis rank, matrix size, finite-coordinate scalar summaries, reduced aggregates, and strict equivalence?

## Main tests

1. Define invariant and complete invariant relative to a fixed equivalence relation.
2. Verify which DSD coordinates are strict-isomorphism invariants.
3. Test whether the displayed finite-coordinate scalar summary is automatically an invariant.
4. Test whether rank, matrix size, or selected scalar summaries are complete.
5. Produce a standard finite-dimensional collision witness for an incomplete invariant family.
6. Produce a standard positive example of a complete classification invariant/canonical form.
7. Audit the overstatement `scalar or finite summary is necessarily incomplete`.
8. Compare the result with downstream static-aggregation and dynamic-readout collision statements.

## Expected classifications

- Direct correspondence where DSD uses ordinary invariant/classification logic.
- Scope qualification where a DSD readout is only a summary unless invariance is separately proved.
- Falsification of any universal claim that rank, scalar codomain, or finite compression is intrinsically incapable of complete classification.

No empirical or dynamical claim is required for the principal proof.
