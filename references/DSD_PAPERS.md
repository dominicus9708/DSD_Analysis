## Citation discipline inside cases

A case should not cite only this registry. `SOURCE_NOTES.md` must identify the exact DSD section/definition/axiom/theorem used.

If the local manuscript title and the current Zenodo landing-page title differ because the Zenodo registry has not yet been updated, record that mismatch explicitly instead of silently choosing one.
