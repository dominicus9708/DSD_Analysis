# Case 005 — Source Notes

## DSD source

Kwon Dominicus, *Formation Axiom System — Dimensional-Structural Describability* (2026).

Relevant formal points:

- Stage V supplies a regime-global partial assignment `q_{L,lambda}: Q_{L,lambda} -> V_{L,lambda}`.
- If an active item lies outside `Q_{L,lambda}`, the assignment is undefined there and is not identified with the distinguished zero or a defined nonzero negligible value.
- Corollary 5.3 states that an undefined assignment is not a value in the current assignment sense and cannot be inferred equal to zero.
- Proposition 5.4 proves that zero-padding loses assignment-domain status.
- Stage VI admits a channel only when `(a,v)` belongs to the local assignment graph. Therefore an undefined assignment yields no channel merely by having a role.

Kwon Dominicus, *Axioms for the Property Structure of Realized Axes in Dimensional-Structural Describability* (2026).

Relevant formal points:

- A property application is undefined when a typed input exists but lies outside the partial property-map domain.
- Defined zero and undefined application are distinct records.

## Strong Kleene source

Melvin Fitting, *Kleene's Logic, Generalized*, Journal of Logic and Computation 1(6), 797–810 (1991), DOI 10.1093/logcom/1.6.797.

Fitting explicitly presents Kleene's strong three-valued logic as having three truth values, informally read as `false`, `true`, and `bottom/unknown`. The truth ordering places the unknown value between false and true, and conjunction/disjunction are meet/join in that truth ordering. Thus the third state is an element of the semantic truth-value carrier and participates in truth-functional operations.

## Source-discipline conclusion

The shared word `undefined/unknown/indeterminate` is not enough to identify the systems.

- K3 third value: a semantic truth value inside its valuation carrier.
- DSD undefined assignment/application: absence of an assignment value at an otherwise relevant typed input because the input is outside the partial-map domain.

Any comparison must preserve that type-level distinction.
