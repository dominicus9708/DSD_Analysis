# Result — LING-003 / Global Case 016

## 1. Main finding

Conversational implicature is an independent pragmatic layer relative to literal asserted content.

The minimal useful decomposition is:

`utterance event -> literal/asserted content -> context-sensitive implicature -> hearer reconstruction`

with explicit separation between speaker implicature and hearer inference.

## 2. Scalar implicature witness

For a sentence of the form `Some S are P`, the literal content is compatible with both:
- some but not all S are P;
- all S are P.

In an ordinary context, a hearer may infer `not all` from the speaker's choice of the weaker expression. But that inference is cancelable by an explicit continuation such as `in fact, all of them are`.

Therefore:

`asserted SOME != implicated NOT_ALL`.

The same asserted semantic content can coexist with different pragmatic states.

## 3. What non-utterance does not license by itself

Failure to utter the stronger alternative `ALL` does not logically equal asserting `NOT_ALL`.

A pragmatic bridge is required, including contextual assumptions and some account of rational/cooperative language use.

Thus:

`not(Assert(ALL))` does not imply `Assert(NOT_ALL)`.

At most, under a supplied pragmatic rule and context, it may support:

`Implicature(NOT_ALL)`.

This is the central predefinition-restraint result.

## 4. Cancellation and historical status

If an implicature is active in one context but canceled in another while literal assertion remains fixed, the pragmatic state cannot be reconstructed from literal semantic content alone.

This is structurally similar to DSD's insistence that reduced or later outputs do not overwrite earlier domain/status distinctions.

A canceled implicature also should not be described as though it had never been a live inference candidate during processing. If historical analysis matters, the inference/cancellation path is distinct from the final literal proposition.

## 5. Speaker versus hearer

Hearer inference is not identical by definition to speaker implicature.
A hearer can over-infer, under-infer, or miss an implicature.

Therefore a robust application must distinguish:
- conventional sentence meaning;
- what is asserted/said in the utterance;
- what the speaker implicates;
- what the hearer reconstructs.

Collapsing these layers would create exactly the kind of cross-regime value substitution that DSD Analysis is designed to audit.

## 6. DSD correspondence

The Formation Axiom System independently preserves staged formation, partial-domain status, and the difference between undefined/absent and defined values. It also does not permit later application-specific structure to be silently imported into an earlier stage.

The linguistic application corresponds structurally as follows:
- literal asserted content is not automatically the pragmatic inference layer;
- a context/pragmatic rule is an external bridge;
- cancellation changes pragmatic status without changing the literal semantic proposition;
- unexpressed stronger content must not be replaced by a normal semantic value merely because a hearer can infer something from its non-use.

This is a structural correspondence, not an identity of formal objects.

## 7. Counterpressure

1. Not every implicature theory accepts every Gricean diagnostic as necessary or sufficient.
2. Some implicatures may be conventionalized or lexicalized to different degrees.
3. Certain inferred contents can also be entailed in special examples; cancelability and entailment interact more subtly than a simple binary division.
4. DSD does not derive cooperative principles, speaker goals, relevance, informativeness, or pragmatic optimization.

Therefore linguistics does not force a unique DSD encoding.

## 8. Final judgment

- **No conflict with the Formation Axiom System was found.**
- **Conversational implicature supplies an independent external node for separating explicit content from context-generated inferred content.**
- **Cancellability gives a finite witness that pragmatic inference is not identical to literal assertion.**
- **The strongest DSD-relevant result is that absence of an explicit stronger statement cannot be totalized directly into a semantic assertion of its negation; a pragmatic bridge must do that work.**
- **This strengthens DSD Analysis through external corroboration rather than establishing a novel theory of pragmatics.**

Overall classification: `structural reinterpretation = supported`, `coherence = supported`, `predefinition restraint = independently corroborated`, `DSD derivation of implicature theory = not supported`.
