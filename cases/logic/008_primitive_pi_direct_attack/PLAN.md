# Case 008 — Primitive PI Direct Attack

## Goal

Directly stress-test Primitive Axis-Property Axiom PI without using analogy to an external logic.

PI states, for each axis-applicable configuration `p`,

`Dom(AxLine_A,p) = C^ax_A,p`,

where `AxLine_A,p : C^ax_A,p ⇀ Gr_1(E^amb_A,p)` is already typed as a partial function.

The attack asks four distinct questions.

1. Can an inherited Stage-VI formation record force PI to fail?
2. Can cardinality or finite-dimensionality prevent total line realization?
3. Is single-line uniqueness actually supplied by PI, or already assumed by the type of `AxLine`?
4. Does PI establish that a selected formation channel deserves axis status, or only totalize a primitive extension choice?

## Falsification targets

A corrective defect would be found if at least one of the following occurs:

- a valid Stage-VI formation record necessarily yields a selected-channel family that cannot be mapped to one-dimensional subspaces under the declared core types;
- PI conflicts with another required axis-property clause;
- a theorem claims line realization to be derived although it is only assumed;
- the paper claims coverage of multi-line/branching realization while its primitive type excludes it.

## Expected outputs

- exact satisfiability theorem for PI over arbitrary selected inherited channels;
- zero-dimensional-carrier obstruction;
- branching/multiline exclusion witness;
- assessment of whether the issue is contradiction, scope limitation, or pre-axiom typing choice;
- paper-revision status.
