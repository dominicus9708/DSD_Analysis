# Describability and Predefinition Justification

Primary purpose: test whether a definition, type, sort, function signature, observer condition, or promotion rule has already excluded alternatives before the intended analysis begins.

## Existing primary nodes

- Case 004 — Free Logic and unjustified formation/existential promotion
- Case 008 — pre-axiom function typing and single-line realization boundary

## Questions

1. Does candidacy silently imply a stronger status?
2. Does a function/sort/signature choice remove candidate structures before axioms are tested?
3. Does a descriptive or observer condition enter as an unacknowledged premise?
4. If the predefinition is weakened, does the conclusion survive?
5. Is the predefinition mathematically necessary, application-specific, or merely convenient?

## Rule

Predefinition is not rejected merely because it is prior. The analysis asks whether the prior definition is justified for the claim being made and whether its exclusion power is stated explicitly.
