# LING-010 / Global Case 023 — Plan

## Topic
Syntax–semantics interface and information structure: focus, topic, alternative sets, and reduced-output loss.

## Primary question
If lexical material and linear order are held fixed, can focus/information-structural marking still change the interpretation or discourse potential? If so, which distinctions must a DSD application preserve without turning DSD into a theory of focus?

## External nodes to test
1. Focus-sensitive interpretation can depend on which constituent is focused.
2. Information-structural differences need not always alter ordinary truth conditions; they may instead alter alternatives, discourse congruence, givenness, or coherence.
3. Competing linguistic theories disagree on how much grammatical status to assign to focus, so DSD must not choose one account silently.

## DSD questions
- Can Formation represent different structured configurations even when lexical material is the same?
- Does a reduced lexical or scalar summary lose focus/topic structure?
- Is Axis-Property actually needed, or would using it for ordinary information-structural marking overfit the linguistic application?

## Expected boundary
Formation should be sufficient for a source-preserving encoding if focus/prosodic/information-structural features are supplied as application data in the configuration. Static Aggregation is relevant only as a warning about lossy reduction. Axis-Property should remain optional and probably unnecessary for the core witness.
