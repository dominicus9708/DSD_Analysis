# Case Summary

MATH-004 compares standard invariant/classification theory with DSD rank, matrix size, finite-coordinate scalar compression, downstream aggregation, and reduced readouts.

## Main result

The DSD results are structurally standard:

- an invariant must be constant on strict-isomorphism classes;
- a complete invariant must separate those classes;
- equal rank or equal matrix size can fail completeness once the full axis-property signature is retained;
- a displayed reduced scalar summary can collide on nonisomorphic models;
- such a collision proves incompleteness only after invariance has been established, otherwise it proves only failure as a classifier/readout;
- no universal theorem says that scalar or finite summaries must be incomplete.

## Standard comparison witness

The zero `2x2` matrix and the nonzero nilpotent Jordan block have the same characteristic polynomial, trace, determinant, and eigenvalue multiset but are not similar.

## Positive boundary

Jordan block data can completely classify similarity when Jordan normal form is available. Thus complete classification depends on retained structure and the declared equivalence relation.

## DSD status

No contradiction found. The current source papers already use the safer terms `summary`, `compression`, `reduced representative`, and `readout`, and demand reconstruction conditions before treating reductions as complete classifiers.
