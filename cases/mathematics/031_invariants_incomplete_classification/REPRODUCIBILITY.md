# Reproducibility

No Python program is required for MATH-004.

The decisive witnesses are exact finite-dimensional constructions:

1. a pair of `2x2` matrices with matching characteristic data and different rank;
2. the DSD rank/property collision already explicitly constructed in the axis-property paper;
3. the Definition-12.3 indicator-map boundary, which follows directly from the definition of an invariant.

All calculations fit in a few lines and are easier to audit symbolically than through code.

Creating a numerical script would not add evidential value and could obscure the logical distinction between:

- invariance,
- completeness,
- injectivity/reconstruction,
- arbitrary reduced readout.

Therefore this case is reproducible from the written definitions and finite witnesses alone.
