## Experiment 45 — Scale-free same-mass response diameter

### Setup

Let \(E_a^{(r)}(S)\) denote the structural-response output at radius \(r\). No absolute coupling is assumed known.

For two nonzero or vector-valued responses \(y,z\), define the common-scale-invariant symmetric discrepancy

\[
d_{\rm sf}(y,z)
=
\begin{cases}
\dfrac{\|y-z\|}{\|y\|+\|z\|},&\|y\|+\|z\|>0,\\
0,&y=z=0.
\end{cases}
\]

For any common nonzero scalar \(\lambda\),

\[
d_{\rm sf}(\lambda y,\lambda z)=d_{\rm sf}(y,z).
\]

Hence an unknown universal response normalization cancels.

For a source descriptor \(Q\) and its fiber

\[
\mathcal F_q=\{S:Q(S)=q\},
\]

define the response diameter

\[
D_{a\mid Q}(r;q)
=
\sup_{S_1,S_2\in\mathcal F_q}
 d_{\rm sf}\!\left(E_a^{(r)}(S_1),E_a^{(r)}(S_2)\right).
\]

For total mass \(T(S)=M\), write

\[
D_{a\mid M}(r;M).
\]

### Exact factorization criterion

At fixed \(r\),

\[
D_{a\mid Q}(r;q)=0
\]

for every admissible \(q\) if and only if the response is constant on every \(Q\)-fiber. Equivalently, a well-defined factor map exists:

\[
E_a^{(r)}=F_r\circ Q.
\]

Thus

\[
\boxed{D_{a\mid M}=0\iff\text{the response factors through total mass at that radius}.}
\]

The criterion does not require a known absolute coupling.

### Nested-descriptor monotonicity

If \(Q_2\) is finer than \(Q_1\), so every \(Q_2\)-fiber is contained in a \(Q_1\)-fiber, then

\[
D_{a\mid Q_2}(r)\le D_{a\mid Q_1}(r).
\]

For the spherical density hierarchy from Experiments 28–31,

\[
M
\prec
(M,I_2)
\prec
C[\rho]\;(\text{full radial profile}),
\]

hence

\[
\boxed{
D_{a\mid C}(r)
\le
D_{a\mid (M,I_2)}(r)
\le
D_{a\mid M}(r).
}
\]

This gives a direct sufficiency test for the minimal source descriptor.

### Verdict

- logarithmic response ratio as the general discrepancy: **REJECTED** because sign and zero responses are problematic.
- common-scale-invariant symmetric discrepancy: **CONFIRMED**.
- zero fiber diameter iff exact factorization through the chosen descriptor: **CONFIRMED**.
- finer source descriptors cannot increase fiber diameter: **CONFIRMED**.

## Experiment 46 — Asymptotic source-structure homogenization

### Non-monotone distance dependence

The same-mass structural response diameter

\[
D_{a\mid M}(r;M)
\]

need not decrease monotonically with distance. Oscillation or intermediate reorganization is logically allowed.

Therefore define the asymptotic envelope

\[
\overline D_{a\mid M}(R;M)
=
\sup_{r\ge R}D_{a\mid M}(r;M).
\]

By construction, \(\overline D\) is nonincreasing in \(R\).

Far-field structural homogenization through total mass is

\[
\boxed{
\overline D_{a\mid M}(R;M)\to0
\qquad(R\to\infty).
}
\]

This means that all source-internal rearrangements inside a fixed total-mass fiber become response-indistinguishable in the far field.

### Diagnostic homogenization radius

For a chosen analytic tolerance \(\epsilon>0\), define

\[
R_{\rm hom}(\epsilon;M)
=
\inf\left\{R:\overline D_{a\mid M}(R;M)\le\epsilon\right\}.
\]

This is a diagnostic convergence scale, not a fundamental support radius and not an observer-resolution-dependent physical constant.

### Important separation

\[
D_{a\mid M}(r;M)\to0
\]

means only that same-mass sources converge to a common response class. It does **not** imply that the common response is inverse-square, nor that it equals any standard gravitational law.

### Verdict

- monotone structural-information erasure with distance: **NOT REQUIRED**.
- asymptotic-envelope formulation: **CONFIRMED**.
- far-field same-mass homogenization implies inverse-square behavior: **REJECTED**.

## Experiment 47 — Three independent amplitude-free tests

Absolute normalization is separated from three logically distinct questions.

### A. Internal-structure universality

At fixed total mass,

\[
U_{\rm str}(r;M):=D_{a\mid M}(r;M).
\]

The far-field condition

\[
U_{\rm str}(r;M)\to0
\]

tests whether internal structure becomes irrelevant at fixed total mass.

### B. Distance exponent

For a spherical source with nonzero scalar radial response \(a_S(r)\), define the finite-difference effective radial exponent

\[
p_{\rm eff}(r_1,r_2;S)
= -\frac{\ln|a_S(r_2)/a_S(r_1)|}{\ln(r_2/r_1)}.
\]

Any common multiplicative coupling cancels.

Inverse-square behavior is tested independently by

\[
\boxed{p_{\rm eff}\to2}
\]

in the intended far-field regime.

This test does not require same-mass structural universality.

### C. Source-mass exponent

For a homologous source family \(S_M\) and fixed radius/regime, define

\[
q_{\rm eff}(M_1,M_2;r)
=
\frac{\ln|a_{M_2}(r)/a_{M_1}(r)|}{\ln(M_2/M_1)}.
\]

Again, any common absolute coupling cancels.

Linear source dependence is tested independently by

\[
\boxed{q_{\rm eff}\to1}.
\]

### Orthogonality of the three tests

The statements

1. \(U_{\rm str}\to0\),
2. \(p_{\rm eff}\to2\),
3. \(q_{\rm eff}\to1\)

are logically independent.

A theory can pass any one or two while failing the others.

Therefore the previously compressed schematic

\[
a\sim K_* M r^{-2}(1+\delta)
\]

must be audited as three separate structural claims before the unknown normalization \(K_*\) is considered.

### Verdict

- internal-structure erasure, distance exponent, and mass exponent are one claim: **REJECTED**.
- all three can be tested without the absolute coupling: **CONFIRMED**.
- absolute-normalization failure prevents these structural tests: **REJECTED**.
