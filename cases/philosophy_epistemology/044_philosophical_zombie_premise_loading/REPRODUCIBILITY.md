## Reproduction procedure

1. Extract the simple zombie argument from SEP without treating it as Chalmers's entire mature position.
2. From Chalmers 2002, record separately:
   - prima facie vs. ideal conceivability;
   - positive vs. negative conceivability;
   - primary vs. secondary conceivability;
   - the restricted bridge `ideal primary positive conceivability -> primary possibility`.
3. Locate the explicit zombie reconstruction using `P` for physical truths and `Q` for a phenomenal truth.
4. Verify that Chalmers states the reconstructed argument is unsound *as it stands* at the primary/secondary step before developing a rescue.
5. Test the prepared falsification conditions independently:
   - Does the source merely define possibility? No.
   - Is observer access part of the core inference? No.
   - Is the argument an inverse inference from identical observations? No.
   - Are bridge principles explicit and contestable? Yes.
6. Compare only the methodological DSD distinction `candidate description != admitted structure without bridge/admission conditions`; do not identify the modal vocabulary with DSD primitives.

## Robustness condition

If a later source shows that a specific formulation uses the zombie scenario only as a conditional illustration and not as evidence for the possibility premise, that formulation must be classified more weakly and must not inherit criticisms aimed at the modal argument.

If a later formulation supplies an independent proof of the contested ideal-conceivability or modal-bridge premise, the current underdetermination judgment must be revised rather than preserved by default.
