## New result
An explicit common-cone countermodel family can be constructed by letting each model \(\mathcal M_\kappa\) use one progression metric for both field propagation and probe kinematics while varying only the source coupling:

\[
\mathcal E_{g_\kappa}[\psi_\kappa]=\kappa\rho,
\qquad
N_\kappa=e^{\psi_\kappa}.
\]

Each \(\kappa>0\) model can satisfy the same single-metric common-cone principle, finite propagation structure, source-additivity architecture, bounded/source descriptor rules, and far-field exponent pattern, while producing a different absolute geometry/acceleration amplitude. Thus the structural principles do not uniquely select \(\kappa\).

For a dimensionless static progression field,

\[
\nabla^2\psi=\mathcal J[\rho],
\]

so \([\mathcal J]=L^{-2}\). A local monomial density source

\[
\mathcal J_p=C_p\rho^p
\]

requires

\[
[C_p]=M^{-p}L^{3p-2}.
\]

In particular, the mass-linear case \(p=1\) requires

\[
[C_1]=L/M,
\]

which is exactly the missing mass-to-geometry conversion dimension. Choosing \(p\neq1\) does not remove the normalization problem; it merely replaces it by a different dimensionful coefficient.

If bounded formation or density shape only supplies source-specific \(M_S,L_S\) and dimensionless structure \(\Pi_S\), any candidate mass-linear coefficient reduces schematically to

\[
C_1(S)=\frac{L_S}{M_S}F(\Pi_S),
\]

which fails source-independent universality under 3D homothetic scaling unless a new absolute scale enters.

## Conditional no-go candidate
If \(\psi\) is dimensionless, the matter/source sector supplies only source-specific mass and length scales plus dimensionless structural data, and no independent universal dimensionful anchor or scale-generating mechanism is supplied, then a unique universal coupling with dimension \(L/M\) cannot be derived from bounded formation, density nonlinearities, common-cone closure, or source additivity alone.

## Verdict

- common-cone structural principles uniquely select source coupling: **REJECTED by explicit model family**
- density nonlinearity removes the dimensionful normalization problem: **REJECTED**
- bounded/source-specific scales alone produce universal \(L/M\): **REJECTED under homothety**
- conditional dimension/scaling non-identifiability theorem: **SUPPORTED / THEOREM CANDIDATE**

The unresolved constant is not hidden in propagation, boundary reference, density profile, or bounded-state discreteness; it is a genuine mass-to-progression-geometry normalization unless a new universal dimensionful anchor is introduced.
