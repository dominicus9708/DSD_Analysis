# Finite Witness — One Borderline Case, Three Semantic Treatments

Take one vague predicate `Tall(x)` and one individual `b` presented as a borderline case by ordinary speakers.

The surface phenomenon is fixed:

`OBS = speakers do not confidently classify Tall(b) as plainly true or plainly false.`

This observation does **not** fix the semantic theory.

| Model | Internal semantic state for `Tall(b)` | Defined ordinary truth value? | Core interpretation |
|---|---|---:|---|
| SV | admissible precisifications disagree | no simple bivalent value | supervaluation-style gap / indecision |
| EP | one sharp Boolean value exists but boundary is unknowable | yes, T or F | epistemicism |
| FZ | `v(Tall(b)) = 0.5` | yes | defined intermediate truth degree |

The three models preserve the same stipulated surface classification difficulty while assigning different semantic structures.

Therefore:

`OBS` does not imply `undefined`.

`OBS` does not imply `false`.

`OBS` does not imply `0.5`.

An application must first supply a bridge selecting or defining the relevant theory.

## Supervaluation mini-witness
Let admissible precisifications be `P={p1,p2}` with

- `p1(Tall(b)) = T`
- `p2(Tall(b)) = F`

Then the atomic predication is not supertrue and not superfalse, while the classical-form compound `Tall(b) OR NOT Tall(b)` is true on both precisifications.

This shows that even a gap treatment should not be represented merely by assigning one ordinary third truth value unless that is explicitly the chosen semantics.

## DSD consequence
The Formation distinction `undefined != defined zero` remains valid, but vagueness cannot be identified wholesale with Formation undefinedness. A fuzzy bridge can place an intermediate degree inside a defined value carrier; an epistemic bridge can keep a Boolean value while attaching a separate accessibility/knowledge status; a supervaluation bridge can represent a family of precisifications and a derived supervaluation status.

Hence DSD's useful role is status preservation and bridge discipline, not theory selection.
