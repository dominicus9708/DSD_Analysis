# Source Notes — LING-006 / Global Case 019

## External linguistic sources

### Stanford Encyclopedia of Philosophy — Dynamic Semantics
Dynamic semantics treats pieces of discourse as instructions that update an existing context; its slogan is that meaning is context-change potential. The framework is abstract and should not be confused automatically with a physical theory of temporal dynamics.
Source: https://plato.stanford.edu/archives/fall2022/entries/dynamic-semantics/

### Stanford Encyclopedia of Philosophy — Discourse Representation Theory
DRT models discourse interpretation by incrementally building a discourse representation structure. Incoming sentences add discourse referents and conditions, and interpretation depends on what the prior discourse has made accessible.
Source: https://plato.stanford.edu/entries/discourse-representation-theory/

### Oxford Handbook — Dynamic Semantics
The standard example `A woman walked in. She sat down.` illustrates that an indefinite can introduce a discourse referent which makes a later pronoun interpretable. Reversing the order does not support the same anaphoric reading. This demonstrates order sensitivity and noncommutative update behavior.
Source: https://academic.oup.com/edited-volume/42642/chapter/358147004

## DSD source boundary

### Formation Axiom System
The Formation Axiom System explicitly declares itself a static typed framework. Its seven-stage order concerns formation inside a fixed descriptive regime and is not a time-evolution law.

### Structural Reorganization Dynamics
The later dynamics paper begins from time-indexed component-resolved states. Its core regular dynamics fixes a Stage-VI formation background; assignment/channel changes require explicit cross-time lineage. Therefore it should not be equated automatically with discourse-information update.

## Source-discipline priority
The linguistic concepts `context`, `discourse referent`, `accessibility`, `update`, and `anaphora` retain their linguistic meanings. Any DSD correspondence is an application bridge, not a replacement definition.
