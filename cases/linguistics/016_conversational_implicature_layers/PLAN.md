# Plan — LING-003 / Global Case 016

## Question
Can conversational implicature be treated as an independent descriptive layer rather than as part of the literal asserted content, and does cancellation show that an inferred pragmatic content must not be silently pre-filled as semantic content?

## External target
- Gricean conversational implicature
- scalar implicature (`some` -> normally `not all`)
- contextual dependence
- cancelability
- distinction among asserted content, speaker implicature, hearer inference, and conventional sentence meaning

## DSD target
Primary: Formation Axiom System.

Relevant DSD distinctions:
- staged formation;
- domain/status preservation;
- undefined or absent state is not a defined zero/value;
- later output cannot be silently identified with an earlier-stage state;
- application bridges must be explicitly supplied.

## Tests
1. Preserve literal assertion while changing/cancelling the implicature.
2. Verify that `not saying all` is not identical to `asserting not all`.
3. Separate speaker implicature from hearer inference so misinference does not become speaker meaning by definition.
4. Identify what extra pragmatic bridge is needed before the implicature is licensed.
5. Test whether DSD merely renames an existing distinction or contributes a useful status-preserving decomposition.

## Expected classification
Structural reinterpretation with coherence and predefinition-restraint relevance; no claim that DSD derives Gricean pragmatics.
