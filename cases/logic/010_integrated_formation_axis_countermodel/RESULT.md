# Case 010 — Result

## Final judgment

**No integrated countermodel was found that falsifies the Formation-to-Axis-Property interface, Primitive PI/PII, or the explicit-completion theorem within the tested class of legal layered presentations.**

The strongest result of the final attack is not that every conceivable geometric interpretation is validated. It is the narrower structural statement that the published interface is internally arranged so that:

1. every full Formation Stage-VI record has at least one Axis-Property extension;
2. nontrivial selected-channel extensions can satisfy PI and PII even under degenerate and failure-bearing downstream data;
3. optional closure/nondegeneracy failure is represented as a derived status rather than converted into model inconsistency;
4. explicit completion adds only functionally determined coordinates and does not feed back into the inherited Formation record;
5. the Axis-Property core factors through Stage VI and is independent of Formation Stage VII.

Accordingly, the 001–010 falsification campaign ends without an internal contradiction, but with several explicit scope limitations and pre-axiomatic commitments identified.

## 1. Stage-VI base obstruction test

The first possible integrated falsifier would be a legal Stage-VI Formation record that admits no Axis-Property extension at all.

No such counterexample exists within the current formal system because the Axis-Property paper provides the trivial extension:

`K_ax_A=empty`,

`Pi_A=empty`,

all optional declaration tags `=0`.

Then PI and PII are vacuous and explicit completion is defined.

Therefore the inherited Formation structure alone cannot force extension inconsistency.

### Important limitation

This is an extension-existence result only. It does not establish that Formation itself forces any nontrivial axis interpretation.

## 2. Nontrivial adversarial extension

A deliberately hostile finite witness was constructed with:

- one describable Formation configuration;
- two distinct Stage-VI operational channel tags differing only in role;
- both tags selected as axes;
- both tags mapped to the same realized one-dimensional line;
- a tag-sensitive unary property assigning different values to those two coincident-line tags;
- a locally instantiated bilinear-dependent property;
- a degenerate zero symmetric bilinear form;
- an active bilinear-dependent formal closure with a deliberately missing required witness;
- an active nondegeneracy declaration on a subspace whose radical is nonzero.

The resulting completed descriptor has

`ClStat=failed`

and

`NonDeg=failed`,

while PI and PII remain satisfied.

No internal contradiction follows.

### Main interpretation

`full axis-property model != every optional property/closure goal succeeds`.

A full model is a typed/coherent primitive presentation satisfying PI–PII together with the exactly determined completion. Negative derived statuses are legitimate data.

## 3. Explicit-completion failure search

The derived stages were audited for nonexistence and nonuniqueness.

### P4

PI makes the already functional primitive `AxLine` map total on selected channels. Hence tagged-axis records, distinct line sets, span, and rank are determined.

Primitive bilinear data determine normal/radical records wherever the bilinear layer is present.

No ambiguity was found.

### P6

Assignment domains and statuses are directly computed from supplied partial property maps.

For homogeneous tag profiles, the line-factor map is generated only when actual fiber constancy holds. In that case ordinary factorization through the line projection gives uniqueness. If fiber constancy fails, the property is tag-sensitive and no line-factor map is required.

Thus a tag-sensitive assignment is not a failed completion.

### P8

Representation values, requirement families, witness checks, closure statuses, cyclic profiles, and nondegeneracy profiles are evaluations of supplied primitive P7 data and earlier derived carriers.

A result value `failed` is still a defined P8 coordinate.

### Verdict

No primitive presentation satisfying the declared typing/coherence clauses and PI–PII was found for which a required derived coordinate is both demanded and undefined.

No pair of different completions over the same primitive data was found either. The completed coordinates are extensional functions of the retained primitive coordinates.

This supports, but does not independently prove beyond the tested audit, the paper's unique explicit-completion theorem.

## 4. PII creates a backward admissibility constraint, not a definitional cycle

The layered order places bilinear-domain data at P3, property assignments at P5, and formal closure declarations at P7. PII then uses actual P5/P7 dependency usage to constrain the earlier primitive bilinear domain.

Define the required-bilinear set

`B_req = { p : some bilinear-dependent property has available profile and nonempty local domain at p, or active formal closure has FormalBilDep(p)=1 }`.

Then PII is exactly the global admissibility requirement

`B_req subset K_bil_A`.

This is a **backward cross-layer constraint** in the presentation, but not a recursive definition:

- `K_bil_A` and its forms are primitive P3 data;
- P5/P7 records are supplied later subject to earlier typing;
- PII is checked as a condition on the completed primitive presentation;
- explicit completion does not add missing P3 data.

Therefore no logical cycle was found.

### Construction-order caveat

The stage numbering should not be interpreted as a naive online algorithm in which P3 is chosen without knowledge of any planned P5/P7 dependency use. A one-pass implementation must either predeclare downstream dependency intent, choose `K_bil_A` sufficiently broadly, or compute the required set from a planned primitive presentation before final validation.

This is an operational construction caveat, not a model-theoretic contradiction.

## 5. No feedback into Formation Stage VI

Extension-level property assignments do not alter Formation assignments, assignment graphs, roles, or admitted operational channels.

Thus an Axis-Property completion cannot retroactively turn an absent Formation channel into an admitted channel, change a defined zero Formation value, or rewrite a Stage-VI tag.

This is crucial for integration: the extension reads the fixed interface rather than modifying it.

No formal claim of syntactic conservativity is inferred from this record-level fact.

## 6. Stage-VII independence survives the integrated attack

The Axis-Property layer depends on the Formation Stage-VI truncation and the shared extension signature, not on post-Stage-VI term spaces, component-term maps, finite-composition domains, or composite-description operators.

Hence two full Formation models with canonically identical Stage-VI records but different Stage-VII component/composite data admit canonically identical Axis-Property structures under the transported shared signature.

No hidden Stage-VII dependency was found.

### Scope boundary

If future DSD work wants axis eligibility, axis properties, or closure conditions to depend on Formation component terms or static composite values, that dependence is not present in the current Axis-Property core and must be introduced by an explicit bridge.

## 7. Where the combined system remains intentionally weak

The final attack confirms that the main unresolved vulnerabilities are not hidden contradictions of completion. They are **bridge and scope choices** already isolated in Cases 008–009:

- which admitted Formation channels should count as axes is primitive extension data;
- one selected channel being represented by at most one line is a pre-PI function-type choice;
- the dependency carrier being a symmetric bilinear form is a pre-PII type choice;
- bilinear-dependency classification is declared rather than derived from Formation;
- PII guarantees availability of bilinear data, not semantic agreement of arbitrary property values with those data;
- failed optional closure and nondegeneracy statuses are allowed and recorded;
- no current bridge derives application-specific physical meaning from these abstract records.

These limitations make the formal core less ambitious, but they also prevent it from silently claiming more than it proves.

## 8. Relation to predefinition non-justification

Cases 004, 008, 009, and 010 now separate four different places where an apparently 'obvious' assumption can enter:

1. **promotion rule** — a stronger status is silently inferred from an earlier one;
2. **signature/type choice** — candidate structures are excluded before axioms are tested;
3. **dependency declaration** — a kind is classified as depending on a particular carrier without deriving that classification;
4. **bridge assumption** — abstract extension data are given application-specific or physical meaning without a constitutive map.

Case 010 found no hidden fifth mechanism in the explicit completion: the completion itself is derived bookkeeping over already supplied primitive choices and declared dependencies.
