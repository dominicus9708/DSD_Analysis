# Structural Gravity Research Log — Experiments 54–56

Date: 2026-09-03

## Experiment 54 — Orthogonality countermodels for the scale-free tests

These are synthetic control models, not proposed gravitational laws. Their purpose is to show that the structural-gravity tests are logically independent.

Let \(K_*\neq0\) be an arbitrary common normalization.

### Control A — baseline structural form

\[
a=K_*\frac{M}{r^2}.
\]

This has

- same-mass structural universality;
- radial exponent \(p=2\);
- mass exponent \(q=1\).

### Control B — distance exponent failure only

\[
a=K_*\frac{M}{r^3}.
\]

Then

- \(U_{\rm str}=0\);
- \(q=1\);
- \(p=3\neq2\).

Thus source universality and mass linearity do not imply inverse-square distance dependence.

### Control C — mass exponent failure only

With a fixed reference mass \(M_0\),

\[
a=K_*\frac{M}{r^2}\frac{M}{M_0}.
\]

Then

- \(U_{\rm str}=0\);
- \(p=2\);
- \(q=2\neq1\).

Thus source universality and inverse-square distance dependence do not imply linear mass dependence.

### Control D — internal-structure universality failure only

Let \(h(S)\) be a bounded dimensionless internal-structure descriptor and \(\epsilon_0\neq0\) be constant in the far field:

\[
a_S=K_*\frac{M}{r^2}[1+\epsilon_0 h(S)].
\]

For homologous source families with \(h\) independent of \(M\),

- each source has \(p=2\);
- source scaling has \(q=1\);
- same-mass sources with different \(h\) have \(U_{\rm str}>0\).

Thus the distance and mass exponents do not imply internal-structure erasure.

### Control E — propagation failure only

Keep the static response

\[
a=K_*Mr^{-2}
\]

but define a source change to update the response at all radii simultaneously at \(t_0\).

Then the three static tests can pass while

\[
v_{\rm onset}>c_{\rm info}
\]

or no finite-propagation cone exists.

Thus static structural success does not imply finite propagation.

### Absolute-normalization degeneracy

Replacing

\[
K_*\to\lambda K_*
\]

leaves all four scale-free tests unchanged.

### Verdict

The four scale-free tests

\[
U_{\rm str},\quad p_{\rm eff},\quad q_{\rm eff},\quad v_{\rm onset}
\]

are logically independent, and all are independent of the absolute normalization \(K_*\).

## Experiment 55 — Compatibility witness with arbitrary absolute normalization

### Static family

Consider the synthetic family

\[
\boxed{
a_S(r)
=K_*\frac{M}{r^2}[1+\varepsilon(r)h(S)]
}
\]

with

\[
|h(S)|\le H,
\]

and assume

\[
\varepsilon(r)\to0,
\qquad
r\varepsilon'(r)\to0.
\]

For sufficiently large \(r\), also require \(|\varepsilon|H<1\) so the correction does not cross a response zero in the audited branch.

### Internal-structure universality

For fixed \(M\), source differences are proportional to \(\varepsilon(r)[h(S_1)-h(S_2)]\). Hence

\[
U_{\rm str}(r;M)\to0.
\]

### Distance exponent

For a differentiable nonzero radial response, the local effective exponent is

\[
p_{\rm loc}(r;S)
=-\frac{d\ln|a_S|}{d\ln r}
=2-
\frac{r\varepsilon'(r)h(S)}{1+\varepsilon(r)h(S)}.
\]

Therefore

\[
\boxed{p_{\rm loc}\to2}
\]

under the stated assumptions.

### Mass exponent

For a homologous family in which \(h(S_M)\) is independent of the overall mass normalization,

\[
a_{S_M}\propto M,
\]

so

\[
\boxed{q_{\rm eff}=1}.
\]

### Finite-propagation completion

Let a source transition change the static profile from \(a_-\) to \(a_+\), and define

\[
a(r,t)
=a_-(r)
+[a_+(r)-a_-(r)]
F\!\left(t-t_0-\frac{d_S(r)}{c_{\rm info}}\right),
\]

where

\[
F(\tau)=0\qquad(\tau<0).
\]

Then no response change occurs before the causal time

\[
t_0+d_S/c_{\rm info}.
\]

The detailed shape of \(F\) remains unspecified and may encode slower response or relaxation.

### Major consequence

All four structural tests can be satisfied simultaneously for **arbitrary nonzero \(K_*\)**.

Therefore

\[
\boxed{
\text{structural consistency of the candidate response class}
\not\Rightarrow
\text{identification of absolute normalization}.
}
\]

This is a compatibility witness: the current structural-gravity constraints are mutually consistent, while the normalization remains underdetermined.

## Experiment 56 — Distortion depth from the response-slope bridge

### Conditional bridge

Adopt the user's structural interpretation in radial form as an explicit conditional bridge:

\[
\boxed{
a_X(r)=-\frac{dX}{dr}}
\]

with far-field reference

\[
X(\infty)=0.
\]

This is a bridge condition, not automatically supplied by the prior source-descriptor analysis.

Using the Experiment 55 family,

\[
a_X(r)
=K_*\frac{M}{r^2}[1+\varepsilon(r)h(S)],
\]

we obtain

\[
X_S(r)
=
\int_r^\infty a_X(u)\,du
=
K_*\frac{M}{r}
+K_*Mh(S)
\int_r^\infty\frac{\varepsilon(u)}{u^2}\,du.
\]

Hence

\[
X_S(r)=K_*\frac{M}{r}+\delta X_S(r).
\]

### Power-decaying structural correction

If for \(u\ge R_0\),

\[
|\varepsilon(u)|
\le
C\left(\frac{R_0}{u}\right)^\alpha,
\qquad \alpha>0,
\]

then

\[
|\delta X_S(r)|
\le
|K_*|MH
\frac{C R_0^\alpha}{1+\alpha}
 r^{-1-\alpha}.
\]

Relative to the coarse distortion depth \(|K_*|M/r\),

\[
\boxed{
\frac{|\delta X_S(r)|}{|K_*|M/r}
\le
\frac{HC}{1+\alpha}
\left(\frac{R_0}{r}\right)^\alpha.
}
\]

Thus a response-slope correction that decays as \(O(r^{-\alpha})\) gives a distortion-depth correction whose **relative** size also decays as \(O(r^{-\alpha})\), while its absolute radial power is one order more negative after integration.

### Interpretation

Under the conditional slope bridge,

\[
\boxed{
a_X\sim r^{-2}\Rightarrow X\sim r^{-1}}
\]

provided the far-field integral exists.

This gives a precise version of the intuition that the acceleration-like response measures the steepness of the structural-distortion profile.

### Limitation preserved

Small field differences do not generally imply small gradient differences without regularity assumptions. Experiment 56 works because an explicit differentiable correction family was supplied and bounded.

### Verdict

- acceleration-like response as radial distortion slope: **CONDITIONAL BRIDGE RETAINED**.
- \(p=2\) plus integrability implies \(X\sim r^{-1}\): **CONFIRMED under the bridge**.
- structural correction decay transfers quantitatively from slope to depth under the stated bound: **CONFIRMED**.

## Consequence for the research line

The current structural-gravity framework now has a nonempty candidate class that simultaneously supports:

1. same-mass structural homogenization;
2. inverse-square response shape;
3. linear source-mass scaling;
4. finite propagation;
5. distortion-depth / response-slope consistency;

while leaving \(K_*\) arbitrary.

This sharply separates **structural-form consistency** from **absolute-normalization derivation**.
