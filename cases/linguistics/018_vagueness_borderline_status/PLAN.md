# LING-005 / Global Case 018 — Vagueness and Borderline Status

## Goal
Test whether vague-predicate borderline cases may be collapsed into `false`, `undefined`, or one intermediate value without first choosing an external theory of vagueness.

## External comparison
Compare at minimum:
- supervaluationism: admissible precisifications and truth-value gaps at simple borderline predications;
- epistemicism: a sharp bivalent boundary exists but its location is unknowable;
- fuzzy / many-valued treatment: borderline predications can receive defined intermediate truth degrees.

## DSD questions
1. Does Formation force any one of these treatments? Expected: no.
2. Can one observed state of classification difficulty correspond to structurally different semantic statuses? Expected: yes.
3. Is `borderline = undefined`, `borderline = false`, or `borderline = 0.5` justified without an application bridge? Expected: no.
4. Does ambiguity Case 017 already cover this? Expected: no; ambiguity concerns multiple distinct interpretations, vagueness concerns borderline application within a selected predicate interpretation.

## DSD scope
Formation Axiom System is primary. Axis-Property is not required unless a later application attaches role- or relation-sensitive properties to a vague predicate.

## Reproducibility
Use a finite comparison table rather than numerical simulation. The witness preserves the same surface classification problem while encoding three incompatible external theories.
