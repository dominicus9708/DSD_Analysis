# LAW-011 Contradiction Audit — Investigative Reconstruction

Status: first-pass contradiction audit complete.

## Candidate C1 — victim/witness perception should equal the historical event

Rejected.

National Academies material shows that perception depends on viewing conditions and memory can later be reconstructed, updated or distorted.

No DSD rule requires an observer's description to be identical to the complete external event.

Result: no contradiction; strong ground-truth identification rejected.

## Candidate C2 — present memory should be a stable copy of the original observation

Rejected.

Memory is source- and time-sensitive. Post-event information and later interactions can change reported memory/confidence.

Result: no contradiction; time-indexed source state required.

## Candidate C3 — more agreeing reports should mean more independent evidence

Rejected.

UK College of Policing guidance on co-witness discussion and information exposure shows that later reports may share common post-event inputs.

Result: `report count != independent-information count`.

## Candidate C4 — physical evidence should function as objective ground truth

Rejected.

NIJ crime-scene guidance explicitly warns of contamination/loss and calls for methodical preservation and combined assessment with case information and witness statements.

Result: physical traces require provenance, preservation and interpretive bridges.

## Candidate C5 — investigation is a monotone triangulation process

Rejected as universal.

A pure intersection model only shrinks candidate histories. Real source reassessment can invalidate an earlier constraint and reopen histories.

Result: use a non-monotonic source-indexed update operator rather than mandatory set intersection.

## Candidate C6 — investigation should only develop the initial accusation hypothesis

Rejected by German StPO §160 as a source-system model. The prosecution office must ascertain both incriminating and exonerating circumstances.

Result: initial suspicion is not the same as final investigative reconstruction.

## Candidate C7 — uncertainty should be forced into a more specific value

Rejected.

UK College of Policing guidance supports allowing `don't know` rather than pushing specificity where the witness is uncertain.

Result: uncertainty is a legitimate source state and should not be pre-filled with a positive or negative answer.

## Candidate C8 — Formation stage chain can be used directly as investigative belief update

Rejected as an application identification.

The external investigative process can be non-monotonic, while Formation stages are not themselves a theory of legal/epistemic belief revision.

A faithful DSD application must use separate time-indexed descriptors and an external update relation if investigative evolution is modeled.

Result: application boundary; no direct Formation contradiction.

## Candidate C9 — observer-dependent describability proves eyewitness psychology

Rejected.

DSD observer/describability distinctions can motivate typed separation, but they do not derive cognitive memory distortion, confidence effects, contamination, or interview psychology.

Result: structural analogy only unless a separate empirical bridge is supplied.

## Candidate C10 — Static Aggregation can combine source reliability automatically

Rejected.

The source materials do not supply universal scalar reliability weights, common codomain, independence model, or aggregation operator.

Result: Static Aggregation not required; external probabilistic/statistical model needed for numerical evidence integration.

## Final contradiction status

No direct contradiction with the current Formation system remains after:

- historical event;
- contemporaneous perception;
- later memory;
- recorded account;
- physical trace;
- provenance/dependence;
- investigative reconstruction;
- institutional factual determination

are typed separately.

The main pressure falls on **DSD application discipline**, especially against:

- omniscient ground-truth assumptions;
- monotone stage identification;
- source-count aggregation;
- automatic reliability weighting;
- forced completion of uncertainty.
