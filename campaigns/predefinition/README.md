Primary purpose: test whether a definition, type, sort, function signature, observer condition, promotion rule, source-independence assumption, temporal overwrite, responsibility transfer, aggregation rule, or instruction-specificity assumption has already excluded alternatives before the intended analysis begins.

## Questions

1. Does candidacy silently imply a stronger status?
2. Does a type/function/signature choice remove candidate structures before testing?
3. Does a descriptive or observer condition enter as an unacknowledged premise?
4. If the predefinition is weakened, does the conclusion survive?
5. Is it mathematically necessary, application-specific, source-defined, or merely convenient?
6. Has a positive **or negative** downstream value been filled before the source transition/substitution rule is identified?
7. Is a later effect being used to back-infer an earlier identity?
8. Is failure of one route treated as proof that all alternative routes are absent?
9. Is a source graph being silently linearized into a mandatory chain?
10. Is report/source multiplicity being treated as independence without provenance/dependence analysis?
11. Is uncertainty being forced into YES/NO/zero?
12. Is hierarchy, office, membership or the same event being used as an automatic responsibility-transfer rule?
13. Is present legal status being used to erase historical operation or residual effect?
14. Is an institutional outcome being used to rewrite each constituent's personal input?
15. Is numerical language being used to justify a scalar aggregation operator that the source does not supply?
16. Is greater descriptive or procedural specification being assumed to produce universally better operational control, even where the source deliberately preserves local discretion?
17. Is a downstream organizational outcome being used to reconstruct which communication, interpretation, or execution interface must have failed?

## Refined rule

Predefinition is not rejected merely because it is prior.

The cross-domain rule is:

**do not pre-fill either a positive or negative downstream status, do not back-infer an upstream identity from a later effect, and do not exclude, merge, transfer, overwrite, aggregate, or over-specify alternative states unless the source or an independently justified bridge supplies the rule that performs or warrants that operation.**

The legal campaign established this for state identity, authority, evidence status, normativity, responsibility, historical reconstruction, legal time, and collective decision formation.

ADMIN-001 independently adds a design boundary: **greater specification is not universally greater adequacy**. Purpose clarity, exact safety-critical coordinates, method constraints, feedback closure, and permitted discretion are distinct variables whose appropriate configuration is source/regime dependent.

This remains an analysis discipline, not a claim that DSD determines the external field's substantive rules or optimal organizational design.
