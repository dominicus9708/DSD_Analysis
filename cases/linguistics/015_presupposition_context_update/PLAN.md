# Plan — LING-002 / Global Case 015

## Primary purpose
Structural reinterpretation.

## Secondary purposes
Coherence, predefinition restraint, context-boundary analysis.

## Target
Presupposition and context update in formal semantics/pragmatics.

## Questions
1. Is asserted content structurally distinct from the presupposed background required for its normal evaluation?
2. Does presupposition failure have to equal ordinary falsity?
3. If a hearer accommodates a missing presupposition, is that an explicit repair/update rather than evidence that the presupposition was already present?
4. Can the DSD Formation system represent the distinction without claiming to derive a theory of presupposition?
5. Does any external theory force the DSD-style partial treatment uniquely?

## Anti-overclaim rule
Presupposition theory is not unified. A correspondence counts only where the source framework itself distinguishes context precondition, assertion/update, and failure/repair. Bivalent analyses and alternative pragmatic theories are retained as counterpressure.

## DSD source lock
Formation Axiom System only for the core comparison: staged formation, partial assignment, undefined versus defined values, and explicit application bridges. Axis-Property machinery is deferred unless context-sensitive property applications later require it.
