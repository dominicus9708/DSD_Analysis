# PHIL-002 / Global Case 045 — Chinese Room Part/System Attribution Audit

Status: **prepared; no verdict precommitted**.

Validation mode: **Mode B — historical convergence / independent rediscovery**, not clean prospective/blind validation.

Reason: the Systems Reply is already known before the case begins, so the analysis cannot honestly be classified as blind with respect to the most famous part/system objection.

## 1. Primary question

Does the Chinese Room argument move from a property judgment about an operator or proper part to a property judgment about the whole room/system without an independently justified attribution bridge?

## 2. Required source reconstruction

Before DSD analysis, reconstruct from primary or authoritative sources:

1. Searle's original Chinese Room setup;
2. the exact conclusion Searle draws from the operator's rule-following;
3. the Systems Reply in its strongest standard form;
4. Searle's internalization response;
5. later formulations only if they materially change the level at which understanding is attributed.

Do not treat a textbook slogan as the original argument.

## 3. Objects and attribution levels to keep separate

At minimum distinguish:

- the human operator;
- the rule book / program;
- memory or symbol stores;
- input/output channels;
- the room as an aggregate physical arrangement;
- the implemented computational system;
- any enlarged internalized system used in Searle's reply;
- external interlocutors who judge the outputs.

## 4. DSD audit questions

### A. Part-to-whole promotion

Test whether

`operator lacks understanding`

is promoted to

`whole system lacks understanding`

without a bridge that specifies how the property of understanding is attributed across parts and wholes.

### B. Whole-to-part promotion

Also test the inverse overreach:

`system understands`

does not automatically imply

`every component understands`.

### C. Role-tag dependence

Ask whether the same underlying component has different relevant properties depending on whether it is treated as operator, memory, transition mechanism, or whole-system component.

### D. External performance versus internal property

Separate:

`output behavior is linguistically adequate`

from

`a specified bearer has semantic understanding`.

Do not infer either direction without a bridge principle.

### E. Internalization response

Audit whether moving the rule book, symbol store, and processing into one person's head changes only the physical boundary of the system or genuinely changes the property-attribution argument.

## 5. Falsification conditions for the DSD attack

The proposed DSD part/whole criticism must be weakened or rejected if:

1. Searle's argument already explicitly targets the whole implemented system rather than inferring from the operator alone;
2. the internalization reply supplies an independent reason that the enlarged whole lacks understanding, not merely that the operator reports no understanding;
3. the Systems Reply depends on a theory of understanding that DSD cannot audit without importing an external semantic theory;
4. the part/whole distinction is only terminological and does not change the inferential burden.

## 6. Historical-convergence test

Because Systems Reply is known, the goal is not to claim prediction.

After source reconstruction, compare the DSD analysis with:

- the classic Systems Reply;

Classify overlap as:

If DSD reaches only the classic Systems Reply, record historical convergence rather than novelty.
