# Case 010 — Integrated Formation + Axis-Property Countermodel Search

## Goal

Attempt to falsify the combined interface between a legal Formation Stage-VI record and a full Axis-Property extension.

This case does not compare DSD with an external logic. It attacks the internal composition of the two published axiom systems after Cases 008–009 separately tested PI and PII.

## Primary questions

1. Can a legal Stage-VI Formation record force every Axis-Property extension to fail?
2. Can PI and PII both hold while explicit completion still fails or becomes non-unique?
3. Can a derived Stage P4/P6/P8 coordinate retroactively invalidate primitive data from an earlier stage?
4. Can an Axis-Property extension modify or contradict the inherited Formation assignment/channel record?
5. Can a valid full model contain failed optional closure or nondegeneracy statuses without becoming inconsistent?
6. Does PII create a genuine definitional cycle because it constrains the earlier P3 bilinear domain using later P5/P7 declarations?
7. Does any Axis-Property coordinate secretly depend on Formation Stage VII rather than the fixed Stage-VI interface?

## Falsification criteria

Case 010 would expose a genuine integrated defect if one of the following is found:

- a full Formation Stage-VI record with no legal Axis-Property extension despite the stated model-existence theorem;
- a layered primitive presentation satisfying all typing/coherence clauses and PI–PII but lacking an explicit completion;
- two distinct explicit completions of the same primitive presentation;
- a derived completion coordinate that changes the inherited Stage-VI Formation record;
- a hidden circular definition that prevents simultaneous interpretation of the layered records;
- an internal theorem that treats a derived `failed` status as both admissible and forbidden.

## Planned stress witnesses

- A vacuous extension over an arbitrary Stage-VI base, to test base-level obstruction.
- A nontrivial two-channel Formation base with distinct operational tags realizing the same axis line.
- A tag-sensitive property on those coincident lines.
- A bilinear-dependent property supplied with a degenerate zero symmetric form.
- An active formal closure whose witness is deliberately missing, producing `failed` rather than model collapse.
- An active nondegeneracy declaration on a degenerate axis-generated subspace, again producing `failed`.
- A paired Stage-VII variation with the same Stage-VI record, to test factorization at the interface.

## Scope discipline

A candidate that violates the shared signature, typing, primitive-stage ordering, or declared function types before PI/PII is not counted as an integrated countermodel. Such cases are pre-axiom scope failures and are recorded separately.

Likewise, failure of an optional closure goal is not automatically failure of the full model unless the formal definition of full model requires that goal to be satisfied.
