## Experiments 216–220 — Progression-field action normalization correction

Use the quadratic progression-field action

\[
S_\psi=\int dt\,d^3x\left[
\frac{\mu_\psi}{2}(\partial_t\psi)^2
-\frac{\mathcal T_\psi}{2}|\nabla\psi|^2
-\frac{\mathcal R_\psi}{2}\psi^2
+\mathcal C_m\rho\psi
\right].
\]

For dimensionless \(\psi\),

\[
[\mu_\psi]=M/L,\qquad
[\mathcal T_\psi]=ML/T^2,\qquad
[\mathcal R_\psi]=M/(LT^2),\qquad
[\mathcal C_m]=L^2/T^2.
\]

The static matter-to-progression amplitude depends on the ratio

\[
\boxed{4\pi\Lambda_t=\mathcal C_m/\mathcal T_\psi}
\]

up to the sign convention. Hence the earlier interpretation of \(\mathcal T_\psi\) alone as the absolute anchor was too strong. A common scaling

\[
(\mu_\psi,\mathcal T_\psi,\mathcal R_\psi,\mathcal C_m)
\mapsto
\lambda(\mu_\psi,\mathcal T_\psi,\mathcal R_\psi,\mathcal C_m)
\]

leaves the classical field equation unchanged. The directly relevant ratios are

\[
\mathcal T_\psi/\mu_\psi,\qquad
\mathcal R_\psi/\mathcal T_\psi,\qquad
\mathcal C_m/\mathcal T_\psi.
\]

The current DSD second-order dynamics already has inertia-, stiffness-, restoration-, and lower-order coupling operator slots, but its \(\mathsf C u\) term is not the external source \(f_{\rm src}\). Therefore the existing coupling slot must not be identified automatically with \(\mathcal C_m\).

### Verdict

- \(\mathcal T_\psi\) alone as absolute coupling anchor: **REJECTED / CORRECTED**
- source amplitude controlled by \(\mathcal C_m/\mathcal T_\psi\): **CONFIRMED within the quadratic specialization**
- existing lower-order coupling operator = matter-source coupling: **REJECTED**
- common action-rescaling degeneracy: **CONFIRMED**

## Experiments 221–228 — Audit of axis-property candidates

### Axis tension

A balance such as

\[
\sum_i\tau_i n_i=0
\]

is homogeneous under \(\tau_i\mapsto\lambda\tau_i\). It may constrain relative directions or ratios but does not determine an absolute magnitude.

### Axis stiffness and inertia

The closest conditional operator roles are

\[
\text{axis stiffness/tension}\to\mathcal K_\psi^{ij},
\qquad
\text{axis inertia}\to\mu_\psi.
\]

In an isotropic branch,

\[
\mathcal K_\psi^{ij}=\mathcal T_\psi h^{ij},
\qquad
c_\psi^2=\mathcal T_\psi/\mu_\psi.
\]

A common cone can therefore impose \(\mathcal T_\psi=\mu_\psi c_*^2\), but the simultaneous scaling of both coefficients remains.

### Restoration

For

\[
\mathcal T_\psi\nabla^2\psi-\mathcal R_\psi\psi=0,
\]

the characteristic screening length is

\[
\ell_R^2=\mathcal T_\psi/\mathcal R_\psi.
\]

An unscreened far-field \(1/r\) branch requires asymptotically negligible \(\mathcal R_\psi/\mathcal T_\psi\). Restoration is therefore a screening/relaxation candidate rather than the monopole normalization anchor.

### Support / boundedness

A regular bounded source can make the self-field integral finite, but an energy-threshold attempt gives schematically

\[
\frac{E_\psi}{Mc_*^2}
\sim
\frac{\mathcal C_m^2}{\mathcal T_\psi c_*^2}\frac{M}{R},
\]

so the source-specific \(M/R\) dependence returns.

### Axis crossing, coupling, reorganization

These can conditionally contribute anisotropic/off-diagonal stiffness, mode mixing, or transition laws, but fixing tensor shape does not determine the common stiffness amplitude.

### Finite countermodel

The earlier realized-axis finite construction allows identical axis lines, rank, bilinear data, and closure while assigning different values to the same unary tension-like property. Therefore axis geometry/rank/closure does not determine the tension-like magnitude.

### Verdict

- axis-tension equilibrium -> absolute tension scale: **REJECTED**
- axis stiffness -> spatial operator shape: **CONDITIONAL**
- axis inertia -> \(\mu_\psi\): **CONDITIONAL**
- restoration -> long-range normalization: **REJECTED; screening candidate**
- bounded support -> universal normalization: **REJECTED; regularization/collapse candidate**
- crossing/coupling -> anisotropic or mode-mixing correction: **CONDITIONAL**

## Experiments 229–236 — Single-metric matter coupling and one-parameter weak-field form

Take a progression metric

\[
ds^2=-e^{2\psi}c_*^2dt^2+h_{ij}dx^idx^j.
\]

The metric alone does not determine the matter-source coefficient. If source and probe matter both use the same universal minimal proper-time action

\[
S_m=-mc_*^2\int d\tau,
\]

then the weak, low-velocity expansion gives

\[
L_m\simeq -mc_*^2-mc_*^2\psi+\frac12mv^2.
\]

Thus the same additional specialization yields

\[
\boxed{\mathbf a=-c_*^2\nabla\psi}
\]

and, up to sign convention,

\[
\boxed{\mathcal C_m=c_*^2}.
\]

If the progression field also shares the same characteristic cone,

\[
\mathcal T_\psi=\mu_\psi c_*^2,
\]

so the weak sector can be written as

\[
\boxed{
\mathcal L_{\rm weak}
=
\frac{\mu_\psi}{2}(\partial_t\psi)^2
-
\frac{\mu_\psi c_*^2}{2}|\nabla\psi|^2
\pm c_*^2\rho\psi
}.
\]

The remaining dimensionful normalization is then one coefficient,

\[
\boxed{\mu_\psi[M/L]},
\]

with

\[
\boxed{|\Lambda_t|=\frac{1}{4\pi\mu_\psi}},
\qquad
\boxed{|K_*|=\frac{c_*^2}{4\pi\mu_\psi}}.
\]

Orientation-invariant projectors \(P_i=n_i\otimes n_i\) can conditionally build the shape of an axis-informed stiffness tensor,

\[
\mathcal K_\psi^{ab}=\sum_i\tau_i w_iP_i^{ab},
\]

but isotropy fixes only tensor shape or dimensionless factors, not the common amplitude. Current realized-axis geometry also provides no physical line measure or universal mass-per-length coefficient by itself.

### Verdict

- single metric alone -> \(\mathcal C_m=c_*^2\): **INSUFFICIENT**
- same metric + universal minimal proper-time matter action -> weak \(\mathcal C_m=c_*^2\): **CONDITIONAL**
- common cone + minimal matter coupling -> one-parameter normalization \(\mu_\psi\): **CONDITIONAL**
- current axis geometry/rank -> universal \(\mu_\psi\): **REJECTED**
- progression-sector inertia amplitude as remaining anchor target: **CONDITIONAL / UNRESOLVED**
