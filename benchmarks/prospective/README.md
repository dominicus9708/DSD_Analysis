# Prospective / Blind Benchmarks

These benchmarks implement Mode C of the DSD Analysis four-mode validation protocol.

## BENCH-C01 — Toxin Puzzle

Path: `benchmarks/prospective/C01_toxin_puzzle/`

Branch: `benchmark/c01-toxin-puzzle-prospective`

Prediction seal: `ad682b7354555de6ad004154e9846e4e1ec31cc7`

Blind integrity: **partial**, not clean.

Reason for downgrade: one secondary lecture snippet exposed a reason-for-action interpretation before the prediction seal. No dedicated objection/reply family was reviewed before sealing.

### Result

Mixed-positive prospective validation.

DSD successfully predicted that the decisive issue lies at the interface among:

- present intention formation;
- anticipated future reasons/motivational structure;
- intention persistence/reconsideration;
- eventual execution.

Post-seal literature strongly confirms that this is the mature structure of the debate.

However:

- Kavka already distinguished reasons for intending from reasons for acting;
- Bratman, Mele, Gauthier, Levy, and later authors developed the same interface in substantially greater detail;
- DSD did not pre-seal the important distinction between normative reasons and motivating/explanatory reasons;
- DSD did not predict Mele’s Ted counterexample;
- no C4 novelty lead was established.

Therefore BENCH-C01 is retained as a **prospective pilot**, not the project’s first fully clean Mode-C validation.
