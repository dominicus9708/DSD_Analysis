# Scope

Global case: 030
Domain case: MATH-003

## Included

- underlying carrier versus enriched structure,
- finite-dimensional vector-space classification by dimension,
- same-carrier nonisomorphic group structures,
- same-vector-carrier inequivalent symmetric bilinear forms,
- realized-axis rank as a coarse invariant,
- bare line versus tagged realized axis,
- tag-sensitive typed properties,
- matrix size versus represented property structure,
- abstract property structure versus optional representation,
- strict equivalence relative to the full DSD axis-property signature.

## Excluded

- dynamical evolution of properties,
- structural reorganization over time,
- physical interpretation of tension/support/inertia labels,
- gravitational or cosmological consequences,
- empirical validation,
- arbitrary classification theory beyond what is needed to test the DSD propositions,
- claims that DSD introduces a new algebraic notion of enriched structure.

## Boundary rule

Any statement about completeness of rank or dimension must explicitly name the signature being classified. Bare vector spaces and enriched axis-property models are not interchangeable comparison categories.
