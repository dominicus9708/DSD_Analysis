# Plan — LING-001 / Global Case 014

## Topic
Expression existence, semantic typing, interpretation definedness, and reference success in formal semantics.

## Primary purpose
structural reinterpretation

## Secondary purposes
coherence / predefinition audit

## DSD target
Formation Axiom System is primary. Axis-Property machinery is not required for the core case.

## External comparison targets
1. compositional semantics;
2. Montague-style semantic typing;
3. functional application and type compatibility;
4. non-denoting terms / free logic;
5. reference success and failure.

## Questions
1. Does the existence of a linguistic expression imply syntactic well-formedness?
2. Does syntactic well-formedness imply semantic type compatibility?
3. Does type compatibility imply that denotation/reference is defined?
4. Does reference failure equal falsity, semantic zero, or expression absence?
5. Does DSD clarify these distinctions without merely renaming existing semantic machinery?

## Anti-bias rule
A correspondence counts only when the external semantic framework independently preserves a distinction. If a standard framework totalizes an interpretation by stipulation, record that as a boundary rather than forcing a DSD-style partial interpretation.

## Expected output classes
- direct structural correspondence;
- correspondence after encoding;
- standard-semantic alternative representation;
- non-correspondence;
- DSD-specific claim not supported by linguistics.
