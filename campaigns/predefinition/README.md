# Describability and Predefinition Justification

Primary purpose: test whether a definition, type, sort, function signature, observer condition, or promotion rule has already excluded alternatives before the intended analysis begins.

## Questions

1. Does candidacy silently imply a stronger status?
2. Does a function/sort/signature choice remove candidate structures before axioms are tested?
3. Does a descriptive or observer condition enter as an unacknowledged premise?
4. If the predefinition is weakened, does the conclusion survive?
5. Is the predefinition mathematically necessary, application-specific, or merely convenient?
6. Has a positive **or negative** downstream value been filled before the source transition/substitution rule is identified?
7. Is a later effect being used to back-infer the identity of an earlier state?
8. Is failure of one ordinary route being treated as proof that all alternative source-defined routes are absent?
9. Is a source graph being silently linearized into a mandatory stage chain?

## Refined rule

Predefinition is not rejected merely because it is prior.

The analysis asks whether the prior definition is justified for the claim being made and whether its exclusion power is stated explicitly.

After the legal campaign, the rule is explicitly two-sided:

**do not pre-fill either a positive or negative downstream status, do not back-infer an upstream identity from a later effect, and do not exclude alternative routes unless the source or an independently justified bridge supplies the rule that performs that promotion, demotion, exclusion, substitution, identification, transfer, or aggregation.**

This is an analysis discipline, not a claim that DSD determines the external field's rules.
