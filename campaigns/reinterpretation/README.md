# Structural Reinterpretation and Application

Primary purpose: use selected DSD distinctions to decompose an external problem without replacing the source discipline's own concepts.

## Candidate domains

- mathematical and philosophical logic
- language and formal semantics
- law, institutions, administration, command and decision structures
- software, security, type systems, and program semantics
- databases and information structures
- ontology and knowledge representation
- philosophy, epistemology, and thought-experiment audit

## Active analyses

- `LAW-001 / Global Case 012` — meeting nonattendance, non-exercise versus invalid ballot, and presumption-of-innocence staging. Primary result: external institutional rules independently preserve several of the same state separations that DSD Formation keeps distinct; the legal burden-of-proof asymmetry remains external normative data rather than a DSD theorem.
- `LAW-002 / Global Case 013` — criminal-trial multi-regime describability. Minimal model separates world reference, evidence sources, prosecution, defence, court, evidence rules, and decision rules. Primary result: one regime's missing description cannot be silently totalized into another regime's positive result; admitted court records may fail to identify a unique world state. Cross-regime transfer and legal norms remain application-supplied structure.
- `LING-001 / Global Case 014` — expression availability, semantic typing, denotation/reference, and defined truth output. Primary result: formal semantics independently distinguishes several stages and status classes, especially non-denotation versus defined falsity, but no unique one-to-one DSD encoding is forced by linguistics.
- `LING-002 / Global Case 015` — presupposition support, asserted content, context update, and accommodation. Primary result: a missing contextual prerequisite need not equal a defined false result, and accommodation is an explicit repair/update rather than evidence that the prerequisite was already present. Presupposition theory remains plural, so the DSD mapping is structural rather than unique.
- `LING-003 / Global Case 016` — conversational implicature, cancellation, and speaker/hearer inference separation. Primary result: literal asserted content can remain fixed while a pragmatic implicature is present or cancelled; failure to utter a stronger alternative is not itself an assertion of the weaker alternative's negation. A context-sensitive pragmatic bridge is required, independently corroborating predefinition restraint without making DSD a theory of pragmatics.
- `LING-004 / Global Case 017` — ambiguity and multiple legitimate interpretation candidates. Primary result: unresolved ambiguity is not mere undefinedness and not a uniquely selected meaning. A faithful DSD application must expose candidate branching or typed tags rather than assign two values to one exact partial-function input. Disambiguation is additional selection structure, so later resolution does not retroactively prove prior uniqueness.
- `LING-005 / Global Case 018` — vagueness and theory-relative borderline status. Primary result: one surface state of classification difficulty is compatible with a supervaluation gap, an epistemically hidden Boolean value, or a defined fuzzy truth degree. DSD therefore must preserve source-theory status and may not silently identify `borderline` with undefined, false/zero, 0.5, or hidden bivalence.
- `LING-006 / Global Case 019` — dynamic semantics, discourse-state update, anaphoric accessibility, and order effects. Primary result: interpretation can depend on the current discourse state and ordered update history; later context does not retroactively license an earlier unavailable reading. The faithful DSD mapping is a sequence of static Formation snapshots connected by explicit external linguistic update bridges, not automatic identification with Structural Reorganization Dynamics.
- `LING-007 / Global Case 020` — speech acts, felicity, role/authority, and downstream effect. Primary result: a meaningful locution does not determine successful illocution, role labels do not derive institutional authority, successful illocution does not guarantee perlocutionary effect, and Austinian misfire differs from abuse. Formation already preserves role in channel identity; Axis-Property becomes structurally relevant but remains optional for explicitly declared tag-sensitive authority/relational records.

## Questions

1. Does DSD remove a real ambiguity, omitted state, or invalid composition step?
2. Is the result merely a renaming of an existing source-theory distinction?
3. Which DSD layer is actually needed: Formation, Axis-Property, both, or neither?
4. Does the case require empirical or numerical testing and therefore belong to a separate benchmark/validation track?

## Rule

External terminology remains primary. DSD correspondence is recorded separately as `direct / partial / after encoding / no mapping`.
