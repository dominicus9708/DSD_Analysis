# Structural Gravity Research Log — Experiments 131–135

Date: 2026-09-03

## Stage
Single-metric common-cone closure versus source-normalization freedom.

## New result
A single-metric progression specialization can reduce the independent common-cone assumptions. If the progression field is minimally coupled to the same progression geometry used by probe kinematics, for example

\[
S_\psi=-\frac12\int \sqrt{|g|}\,Z(\psi)g^{\mu\nu}\partial_\mu\psi\partial_\nu\psi+\cdots,
\]

then wherever \(Z>0\) the scalar principal symbol is

\[
P_\psi=Z\,g_{\rm prog}^{\mu\nu}\xi_\mu\xi_\nu,
\]

so the progression field and probe geometry share the same characteristic cone by construction. This is a structural-gravity downstream specialization, not a result already forced by the DSD core.

However, common-cone closure does not determine the mass-to-progression amplitude. In a weak-field linear specialization

\[
Z\Box_{g_{\rm prog}}\psi=\alpha\rho,
\]

the characteristic cone depends on the principal part, while the static spherical amplitude satisfies, up to sign convention,

\[
\psi(r)\sim\frac{\alpha}{4\pi Z}\frac{M}{r}.
\]

Hence

\[
\Lambda_t=\frac{\alpha}{4\pi Z}
\]

remains an independent source-normalization ratio.

The boundary condition \(\psi(\infty)=0\) fixes only an additive reference. A shell balance

\[
\oint_{S_r} Z\nabla\psi\cdot d\mathbf A=\alpha M
\]

can fix the \(r^{-1}\) geometry shape and source exponent \(M^1\), but it still leaves \(\alpha/Z\) free.

## Verdict

- single progression metric can enforce common cone for field and probe sectors: **CONDITIONAL**
- common cone fixes \(\Lambda_t\): **REJECTED**
- asymptotic reference condition fixes \(\Lambda_t\): **REJECTED**
- shell conservation fixes distance/source exponents but not absolute amplitude: **CONDITIONAL / CONFIRMED**

## Impact on the current logic chain
The speed problem and the absolute-coupling problem are now algebraically separated. A single-metric principle can potentially reduce \(c_{\rm kin}\) and \(c_{\rm info}^{(\psi)}\) to one cone, but the missing dimensionful quantity survives entirely in the source coupling. Causal closure therefore cannot by itself solve the \(L/M\) normalization problem.
