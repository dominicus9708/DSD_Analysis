# Standard Mathematics Sources

## Encyclopedia of Mathematics — Semi-lattice

Relevant standard fact: a semilattice is a commutative idempotent semigroup, and the free join-semilattice on a set `X` is the set of all finite subsets of `X` ordered by inclusion. For the present case, union is the join operation and the empty set supplies a bottom/identity for union.

Source: https://encyclopediaofmath.org/wiki/Semi-lattice

## Encyclopedia of Mathematics — Monoid

Relevant standard fact: a monoid is a semigroup with identity; in a commutative monoid the operation is often written additively and the identity as zero.

Source: https://encyclopediaofmath.org/wiki/Monoid

## Encyclopedia of Mathematics — Set function / additive set function

Relevant standard fact: a finitely additive set function satisfies finite additivity on pairwise disjoint domain sets. The target may be vector-valued or group-valued in standard generalizations.

Source: https://encyclopediaofmath.org/wiki/Additive_set_function

## Encyclopedia of Mathematics — Ring of sets

Relevant standard fact: a ring of sets contains the empty set and is closed under finite union and set difference. `P_fin(C)` is therefore a ring of sets for any carrier `C`, because finite unions and differences of finite sets remain finite.

Source: https://encyclopediaofmath.org/wiki/Ring_of_sets

## nLab — Free commutative monoid

Relevant standard fact: the free commutative monoid on a set `S` may be represented by finitely supported functions `S -> N`, equivalently finite multisets/formal finite natural-number combinations. This retains multiplicity, unlike ordinary finite subsets.

Source: https://ncatlab.org/nlab/show/free+commutative+monoid

## Use rule

These sources define the external mathematical structures. DSD terminology is not substituted into their definitions. The comparison is performed only after the external structure has been stated independently.
