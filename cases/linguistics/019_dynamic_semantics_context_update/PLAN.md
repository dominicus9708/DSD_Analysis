# LING-006 / Global Case 019 — Dynamic semantics and context update

## Goal
Test whether discourse interpretation requires preserving ordered context change rather than treating meaning as one static value, and identify the boundary between linguistic dynamic semantics and DSD static/dynamical layers.

## External targets
- Dynamic semantics: meaning as context-change potential.
- Discourse Representation Theory: discourse referents and anaphoric accessibility.
- Order effects in inter-sentential anaphora.

## DSD questions
1. Can Formation alone represent change of discourse state inside one fixed model?
2. Is a sequence of static Formation snapshots plus an external update bridge more faithful?
3. Does later context retroactively license an earlier unavailable interpretation?
4. Does equality of truth-conditional output imply equality of discourse/update structure?
5. Is Structural Reorganization Dynamics genuinely required, or would using it here conflate linguistic update with physical/structural temporal evolution?

## Working hypothesis
Use Formation snapshot-by-snapshot. Treat utterance update maps as application-supplied bridges. Do not identify linguistic dynamic semantics with DSD Structural Reorganization Dynamics without an explicit cross-domain interpretation.
