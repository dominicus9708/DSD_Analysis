# Lexical-Semantic Audit — Freedom / Liberty / Freiheit / Liberté / Libertad / 自由 / 자유

Status: exploratory source audit. This file does **not** infer national character from dictionary meanings.

## Audit rule

`same translation label != same lexical field != same legal concept != same political philosophy`

The comparison unit is `language × source type × historical period × domain`, not nationality.

## DSD relevance

Machine translation or bilingual glossing can map several source terms into one Korean term `자유` or several Korean terms into `freedom`. That output equality does not reconstruct the lost source distinctions.

`translation equality != source-structure equality`

The DSD application should therefore preserve:
- source language;
- source term;
- dictionary/legal/philosophical domain;
- period;
- neighboring antonyms/pejoratives;
- explicit bridge used for translation;
- information lost in the reduced translation.
