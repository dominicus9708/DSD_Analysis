# MATH-003 — Same Carrier, Different Enriched Structures

Global case: 030
Status: **first-pass analysis complete**
Primary verdict: **direct correspondence with a signature-scope qualification**

## Core result

The DSD distinction between:

- underlying carrier / realized lines / rank,
- tagged axes,
- typed property assignments,
- bilinear and closure data,
- optional representations,
- full strict equivalence

matches the ordinary mathematical distinction between an underlying carrier and additional structure defined on it.

Equal carrier, equal realized-axis rank, or equal matrix size do not generally classify the full enriched structure.

However, rank/dimension can be complete for a narrower signature: finite-dimensional vector spaces over a fixed field are classified by dimension.

## DSD consequence

The safe formulation is therefore:

> realized-axis rank is not a complete classifier of the full axis-property signature.

It should not be generalized into the stronger and false statement that dimension/rank is never a complete invariant.
